# v7.1.5 Eval Report Dashboard

## Status

Implemented on `dev/v4.19` and tagged as `v7.1.5`.

## What Changed

- Added `safecode.eval.dashboard` for Markdown eval dashboard rendering.
- Added `sac eval --mode dashboard`.
- Summarized latest live eval, SWE-bench Lite, and real-task JSON reports.
- Surfaced missing report sources, aggregate pass rate, per-suite pass rate, and
  compact failure lines.
- Saved the default dashboard artifact to `.sac/eval/dashboard.md`.

## Acceptance

- `uv run pytest tests/test_eval_report_dashboard.py -q`
- `uv run sac eval --mode dashboard --dashboard-output /tmp/safecode-eval-dashboard.md`
- `uv run pytest tests/test_release_metadata.py tests/test_versions_json_sync.py -q`

## Notes

The dashboard is intentionally Markdown-first so it can be attached to CI runs,
release notes, or local audit artifacts without a web server.
