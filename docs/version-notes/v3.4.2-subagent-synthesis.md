# v3.4.2 — Subagent Synthesis (T-3.4.2-A)

## Summary

Adds parent-side synthesis of merged subagent findings via `synthesize_findings()`
in `src/safecode/subagents/synthesis.py`. The agent loop now calls synthesis before
consuming the merged finding list. Synthesis output is redacted before context
injection. If synthesis fails, merged findings are preserved and a `RuntimeWarning`
is emitted without crashing the loop. The original findings list is never mutated.

## Key Changes

- **`src/safecode/subagents/synthesis.py`** (new):
  - `SubagentSynthesisResult` (frozen dataclass): `summary`, `key_findings`, `risks`,
    `source_task_ids`, `used_fallback`.
  - `synthesize_findings(findings, llm_client=None, *, max_findings=10)`: calls LLM
    if available; falls back to deterministic local extraction if LLM is unavailable
    or fails. Output redacted via `redact_secrets`. Never raises. Never mutates input.
  - `source_task_ids` sorted for determinism.
- **`src/safecode/agent/loop.py`**: `_enrich_with_subagent_findings()` now calls
  `findings_from_journal_events` + `merge_subagent_findings` separately, then
  calls `synthesize_findings(findings, self.llm_client)` before parent consumption.
  Synthesis result injected as `context["subagent_synthesis"]`. On synthesis failure,
  `RuntimeWarning` emitted and merged findings remain intact in context.
- **`tests/test_subagent_synthesis.py`** (new): 28 tests covering: parent calls
  synthesis before consumption, output redaction, original list unchanged, empty
  findings, fallback safety, source ID determinism, no real network calls.
- **`tests/test_subagent_redaction.py`** updated: patch targets updated from
  `merge_journal_subagent_findings` to the new `findings_from_journal_events` +
  `merge_subagent_findings` pair.

## Acceptance

- `PYTHONPATH=src python3 -m pytest tests/test_subagent_synthesis.py tests/test_subagent_redaction.py tests/test_subagent_orchestration.py -q`
