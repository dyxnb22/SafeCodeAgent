# v3.4.3 — Subagent Payload v2 (T-3.4.3-A)

## Summary

Bumps `SubagentDispatchPayload` to `payload_version=2`, adding synthesis and
cancellation fields. v1 payloads load tolerantly with safe defaults for all new
fields. Unsupported future versions warn and fail closed. Malformed payload
warnings do not leak caller-supplied content. Subagent payload v2 is promoted to
supported in `docs/public-contracts.md`.

## Key Changes

- **`src/safecode/subagents/payload.py`**:
  - `CURRENT_PAYLOAD_VERSION = 2` (was 1).
  - `SUPPORTED_PAYLOAD_VERSIONS = frozenset({1, 2})` (v1 remains supported).
  - Pydantic model default for `payload_version` stays 1 for backward compat
    (old journals without the field parse as v1); new journals use
    `CURRENT_PAYLOAD_VERSION=2` via the write path.
  - New v2 fields with safe defaults: `synthesis_summary`, `synthesis_key_findings`,
    `synthesis_risks`, `synthesis_source_task_ids`, `cancelled_task_ids`.
- **`src/safecode/state/journal.py`**: `record_subagent_dispatch` uses
  `CURRENT_PAYLOAD_VERSION` (2) as the default payload version.
- **`src/safecode/subagents/journal_adapter.py`**: comment noting v2 fields are
  read but synthesis is handled separately by `synthesize_findings` in the loop.
- **`tests/test_subagent_journal_payload_versioning.py`** extended:
  - Updated: `test_current_payload_version`, `test_version_2_is_supported`,
    `test_record_adds_payload_version`, `test_future_version_fail_closed`.
  - New: `TestPayloadV2Fields` (6 tests), `TestPayloadV2JournalRoundTrip` (3 tests),
    `TestPayloadV2UnsupportedFutureVersion` (3 tests).
- **`docs/public-contracts.md`**: subagent v2 payload promoted to supported.

## Invariants

- v1 payloads still load with defaults (full backward compat).
- v2 payloads round-trip synthesis and cancellation fields.
- Future version ≥ 3: `RuntimeWarning` + `None` return (fail closed, no crash).
- Malformed payload warnings do not include task IDs, summaries, or other
  caller-supplied content that could contain secrets.

## Acceptance

- `PYTHONPATH=src python3 -m pytest tests/test_subagent_journal_payload_versioning.py tests/test_subagent_synthesis.py tests/test_public_contract_snapshots.py -q`
