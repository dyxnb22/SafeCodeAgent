# v6.33.0 — context-back-pressure

Adds model-window-aware context budgets and compaction thresholds.

## Changes

- `ModelContextProfile`: infers conservative context windows for DeepSeek,
  Anthropic/Claude, and OpenAI-family model names.
- `effective_context_budget()`: keeps explicit `max_context_chars` overrides,
  while allowing default-budget non-mock models to expand to safe input budgets.
- `ContextCollector` and `sac context explain` now use the effective budget.
- `AgentLoop` compaction now derives `max_context_tokens` and threshold ratio
  from the model profile when available.
