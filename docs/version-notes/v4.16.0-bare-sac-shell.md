# v4.16.0 - Bare sac Enters Shell, 7-Command Help Surface

## Summary

TTY `sac` with no subcommand enters the interactive shell. Daily help surface
trimmed to 7 commands. `sac help --all` shows the full surface.

## Changes

- `sac` (no args, TTY): enters interactive shell (unchanged — already shipped).
- `sac --help`: trimmed to 7 daily commands: init, ask, edit, apply, fix, commit, doctor.
- `sac help --all`: new command showing full command surface including hidden.
- 13 commands hidden from root help: quickstart, status, task, rollback, run,
  profile, resume, memory, debug, shell, model, provider, version.
- All hidden commands remain callable.

## Tests

- `tests/test_cli_default_is_shell.py`: 4 tests for help surface and callability.
- Help surface tests updated for 7-command surface.

All existing tests pass. No stable contract changes.
