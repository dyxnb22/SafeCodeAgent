# v4.7.0 Failure Taxonomy and Debug Last-Failure

Status: implemented.

## Scope

- T-4.7.0-A runtime-failure-taxonomy
- T-4.7.0-B sac-debug-last-failure

## Implementation Notes

- Added experimental `FailureCategory` values and a single suggested-command table in `src/safecode/core/failure_category.py`.
- Added an optional `failure_category` field to runtime log events; old log lines without the field continue to parse.
- Added redacted category breadcrumbs across CLI, orchestrator, shell, sandbox preflight, MCP runner, and agent-loop failure paths.
- Added experimental `sac debug last-failure [--task <id>] [--json]`, registered under `sac debug`.
- `last-failure` is read-only: it reads runtime logs, task sidecars, recent-failure memory, and audit events without executing commands.
