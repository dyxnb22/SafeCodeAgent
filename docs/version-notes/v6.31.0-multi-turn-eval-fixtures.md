# v6.31.0 — multi-turn-eval-fixtures

Adds eight validation-backed live eval fixtures that model multi-turn repair
work instead of one-shot edits.

## Changes

- `src/safecode/eval/live.py`: adds `multi-turn-*` fixtures for wrong imports,
  partial renames, chained type errors, test-first work, config cascades, import
  cycles, async/sync mismatches, and regression guards.
- Each new fixture has a real `pytest` success condition plus
  `validation_commands`, relevant-file metadata, symbol metadata, and repair
  attempt allowance.
- `tests/snapshots/live_eval/baseline.json`: expands the fixture ratchet from
  28 to 36 default fixtures.
- `tests/test_live_eval_mode.py`: verifies fixture count, names, and multi-turn
  metadata.

## Verification

```bash
uv run pytest tests/test_live_eval_mode.py -q
```
