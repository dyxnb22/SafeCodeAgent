# v3.6.4 — Threat Model Documentation

## Summary

Adds `docs/security/threat-model-v3.6.md` covering the full threat model for
SafeCode Agent. Documents attacker personas, mitigations, and a semi-annual
review cadence. Extends `tests/test_threat_model_docs.py` to enforce all
required headings.

## Personas Covered

- **Local user**: audit anchor, hash chain, user-level safety knobs.
- **Malicious repo**: secret filename filtering, redaction, filesystem boundary.
- **Malicious project config**: strictness-wins merge, network lockdown,
  provider redirection prevention.
- **Malicious MCP server**: static classification wins, max output size,
  call_args never in error text, write tool gating.
- **Malicious model output**: JSON schema validation, diff preview gate,
  static tool routing, filesystem boundary, checkpoint before write.
- **Network and provider risk**: network disabled by default, allowlist, user-only
  provider config, no telemetry in retry warnings.
- **Audit and approval trust boundaries**: append-only log, hash chain,
  out-of-project-root anchor, single-use approvals.
- **Sandbox limitations**: backend unavailability fails closed, no privileged
  mode, network disabled by default, sensitive path rejection.
- **Telemetry and update-check**: PyPI-only fetch, no user data, OTel opt-in,
  no background processes.

## Review Cadence

Semi-annual (next: 2026-12-01) or on any new execution surface or trust
boundary change.

## Tests

`tests/test_threat_model_docs.py` — 14 tests enforcing document existence,
all required section headings, and key invariants.
