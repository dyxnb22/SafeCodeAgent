# v3.4.1 — Subagent Cancellation (T-3.4.1-A)

## Summary

Adds parent-side cancellation for running subagents via `CancellationToken` in
`src/safecode/subagents/pool.py`. Cancellation is idempotent, completes within 5
seconds in tests, and leaves no orphan files, journal files, or dangling thread
handles. Cancelled tasks are marked `blocked=True` in the result set.

## Key Changes

- **`CancellationToken`** (in `pool.py`): `threading.Event`-backed, idempotent
  `cancel()`, thread-safe `is_cancelled()`.
- `SubagentPool.cancel()` signals the pool's internal token; external tokens can
  be passed to `run_all(cancellation_token=...)` for parent-level control.
- Tasks checked before execution: if token is cancelled, task returns a blocked
  `SubagentResult` immediately with no file I/O.
- Result ordering by `task_id` is preserved even when some results are cancelled.
- **`tests/test_subagent_cancellation.py`** (new): 12 tests covering idempotency,
  cancelled-result shape, 5-second bound, ordering, and no-orphan-file invariant.

## Acceptance

- `PYTHONPATH=src python3 -m pytest tests/test_subagent_cancellation.py tests/test_subagent_pool.py tests/test_subagent_orchestration.py -q`
