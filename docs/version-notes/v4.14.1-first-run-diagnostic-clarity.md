# v4.14.1 - First-run Diagnostic Clarity

## Summary

Adds top-line verdicts to `sac doctor` and `sac provider status`, next-command
hints on every failed diagnostic row, and provider-readiness honesty in
`sac quickstart`.

## Changes

- `sac doctor`: Prints `Overall: READY` or `Overall: NEEDS SETUP — N issue(s)`
  before the diagnostic table. Every failed row carries a `Next:` hint with a
  concrete command.
- `sac provider status`: Opens with a one-line `Verdict: READY/BROKEN` line;
  existing detail blocks move under a `Details:` section.
- `sac quickstart`: Refuses to recommend a live-provider demo when the
  effective provider/key/network state is not ready; prints `Run: sac doctor`
  instead. Explicit `--demo` flag still materializes demo projects.

## Tests

- `tests/test_doctor_top_line_verdict.py`: 7 tests covering verdict line,
  next-command hints in diagnostics, and EXPERIMENTAL exclusion from verdict.
- `tests/test_provider_status_verdict.py`: 6 tests covering READY/BROKEN
  verdict, Details section, and quickstart provider-not-ready behavior.

All existing tests pass. No stable contract changes.
