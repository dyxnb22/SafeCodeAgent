# v3.5.2 — Interactive TUI (experimental)

## Summary

Adds a minimal interactive TUI command `sac tui interactive`.
Textual is not a current dependency; a conservative terminal-safe
implementation using Rich Live display is used instead.

## New files

- `src/safecode/tui/interactive.py` — `run_interactive(project_root, *, refresh_seconds, history_limit)`.
  Non-TTY: calls `_print_static()` → prints dashboard snapshot and returns.
  TTY: calls `_run_live()` → Rich `Live` display, refreshes every `refresh_seconds`, Ctrl-C exits.
- `tests/test_tui_interactive_smoke.py` — 24 new tests.

## Changes

- `src/safecode/cli_tui.py`: adds `sac tui interactive` command with `--refresh` and
  `--history-limit` options.

## Invariants

- Non-TTY mode (`sys.stdout.isatty() == False`) always exits 0 without blocking.
- Non-TTY output is deterministic (same output on repeated calls for same state).
- Output contains session, plan, pending diff, and history sections.
- Ctrl-C in TTY mode exits cleanly (no traceback).
- `sac tui dashboard` (existing command) is unchanged.

## Experimental label

TUI surfaces remain EXPERIMENTAL.
