# v2.6.15 — Release Changelog Generator

## Summary

Adds a read-only `sac release changelog` command that generates Markdown from
local `docs/version-notes/vX.Y.Z-*.md` files.

## What changed

- `src/safecode/release/changelog.py` (new): parses version-note filenames,
  headings, and summary sections.
- `src/safecode/cli_ops.py`: adds `sac release changelog --from X.Y.Z --to X.Y.Z`.
- `tests/test_release_changelog.py`: focused parser, renderer, and CLI tests.
