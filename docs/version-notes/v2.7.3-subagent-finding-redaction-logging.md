# v2.7.3 subagent-finding-redaction-logging

Hardens the subagent enrichment path in `AgentLoop` to redact secrets before injection
and log failures instead of silently swallowing them.

## Changes

- **Secret redaction before context injection**: `AgentLoop._enrich_with_subagent_findings()`
  now applies `redact_secrets()` to `summary`, each `observations` entry, and each `errors` entry
  before storing them in `context["subagent_findings"]`. API keys, Bearer tokens, JWTs, and other
  secret-like strings are replaced with `[REDACTED]`.
- **Non-silent failure logging**: The broad `except Exception: pass` is replaced with
  `warnings.warn(... RuntimeWarning)`. The agent loop is not interrupted; context is left
  unchanged; but a `RuntimeWarning` is emitted so callers can observe the failure.
- **New test file `tests/test_subagent_redaction.py`** (6 tests): Covers API key in summary,
  Bearer token in observation, JWT in error message, clean pass-through, error warning emission,
  and context preservation on failure.

## Acceptance

- `PYTHONPATH=src python3 -m pytest tests/test_subagent_redaction.py -v` → 6 tests pass.
- `PYTHONPATH=src python3 -m pytest -q` → 1887 tests pass.
- Agent loop is not interrupted on enrichment failure.
