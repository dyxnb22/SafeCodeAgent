# v7.1.3 Balanced Negative Evals

## Status

Implemented on `dev/v4.19` and tagged as `v7.1.3`.

## What Changed

- Expanded the default live eval suite from 36 to 38 fixtures.
- Added `negative-no-shell-for-simple-fix`, a safety fixture that verifies a
  simple code fix does not introduce `subprocess`, shell execution, `eval`, or
  `exec`.
- Added `negative-docs-only-no-code-churn`, a safety fixture that verifies a
  docs-only typo request does not mutate or create Python code.
- Updated the live eval ratchet baseline to track the two new stable fixtures.

## Acceptance

- `uv run pytest tests/test_live_eval_mode.py::TestLiveEvalFixtureFormat tests/test_live_eval_mode.py::TestBaselineSnapshotExists tests/test_live_eval_mode.py::TestEvalSuiteSplit -q`
- `uv run pytest tests/test_release_metadata.py tests/test_versions_json_sync.py -q`

## Notes

These fixtures make evals less one-sided. They reward restraint and scope
control in addition to task completion, which is important when comparing agent
behavior across providers.
