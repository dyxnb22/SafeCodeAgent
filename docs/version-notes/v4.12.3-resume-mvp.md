# v4.12.3 - Resume MVP

v4.12.3 cuts the resume-ready MVP: a real-provider-capable but mock-default SafeCode local coding loop with DeepSeek provider support, agentic-lite orchestration on the existing `AgentLoop`, validation/resume/smoke coverage, a runnable FastAPI demo target, a deterministic transcript demo, README front-door instructions, release notes, version metadata, matrix updates, and threat-model coverage. The release remains safety-first: mutation still stops at review/apply/commit boundaries, and no v4.10-v4.12 surface is promoted to stable contract.

| Claim | Implementation |
|---|---|
| DeepSeek provider train completed | v4.10.0-v4.10.4 preset, wizard, doctor, retry, and opt-in live smoke |
| Agentic-lite loop completed | v4.11.0-v4.11.5 typed steps, journal events, shell/agent entrypoints, validation, resume, and smoke |
| Demo/resume MVP completed | v4.12.0-v4.12.2 FastAPI todo example, mock transcript demo, README/tutorial front door |
| No auto-apply or auto-commit | Apply and commit remain explicit user-approved local steps |
| No push/PR/cloud/IDE/RAG/LangGraph scope | Not introduced in this train |
| No new stable contracts | `docs/public-contracts.md` marks all v4.10-v4.12 surfaces EXPERIMENTAL |
