# v4.10.0 — DeepSeek Provider Preset

## Summary

Adds `provider = "deepseek"` support to the factory and `OpenAICompatibleLLMClient`.
`src/safecode/llm/deepseek.py` defines the preset table mapping `deepseek` to
`{base_url: "https://api.deepseek.com", default_model: "deepseek-v4-pro",
api_key_env: "DEEPSEEK_API_KEY"}`. The factory routes to
`OpenAICompatibleLLMClient` using preset defaults when config fields are blank;
explicit user config is never overwritten. The client gains `api_key_env`
resolution (env var lookup order: provider-supplied → `OPENAI_API_KEY` →
`SAFECODE_LLM_API_KEY`) and endpoint normalization that joins
`/v1/chat/completions` onto `config.llm.base_url` while avoiding double-append
for callers that have already supplied a full path.

## Changed Files / Modules

- `src/safecode/llm/deepseek.py` (new): preset table for `deepseek` provider.
- `src/safecode/llm/factory.py`: route `deepseek` provider to `OpenAICompatibleLLMClient`.
- `src/safecode/llm/openai_client.py`: `api_key_env` resolution and endpoint normalization.
- `src/safecode/config.py`: added `deepseek` to provider docstring.
- `tests/test_llm_deepseek_preset.py`: preset defaults, factory routing, env var resolution,
  endpoint normalization, double-append prevention.
