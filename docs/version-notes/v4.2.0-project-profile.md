# v4.2.0 — Project Command Profile

## Summary

v4.2.0 adds a project command profile detector and `sac profile` CLI (EXPERIMENTAL).
The profile captures test/lint/typecheck/build commands for Python, Node, Go, and Rust
projects, persists them to `.sac/project_profile.json`, and respects user overrides that
survive re-detection. No stable contract changes.

## Tasks

### T-4.2.0-A project-profile-detector

New `src/safecode/project/profile.py`:

- `ProfileCommand(BaseModel, frozen)`: `command: tuple[str, ...]`, `stack: str`,
  `source: Literal["detected", "user", "none"]`, `missing_dependency: bool`.
- `ProjectProfile(BaseModel, frozen)`: `payload_version=1`, `test/lint/typecheck/build:
  ProfileCommand | None`, `user_overrides: frozenset[str]`.
- `detect_profile(project_root)` — detects commands from project manifests;
  never executes project commands; user overrides always win.
- `save_profile(project_root, profile)` — atomic write via tmp+os.replace.
- `load_profile(project_root)` — returns None on missing or corrupted file.
- `apply_user_override(project_root, kind, argv)` — sets user override and persists.
- `clear_user_override(project_root, kind)` — clears override and re-detects.

Detection stacks:

| Stack | test | lint | typecheck | build |
|---|---|---|---|---|
| Python | pytest -q (uv run if uv.lock) | ruff check . | mypy . | — |
| Node | npm/pnpm/yarn test (from scripts) | npm run lint | npm run typecheck | npm run build |
| Go | go test ./... | go vet ./... | — | go build ./... |
| Rust | cargo test | cargo clippy --no-deps | cargo check | cargo build |

Missing-tool detection uses `shutil.which(head_argv)`. Marks `missing_dependency=True`
but keeps the command visible — downstream callers decide how to handle it.

### T-4.2.0-B sac-profile-cli

New `src/safecode/cli_profile.py` registered as `profile` in `cli.py`:

- `sac profile detect` — detect and persist; user overrides preserved.
- `sac profile show [--json]` — display current profile; deterministic JSON shape.
- `sac profile set <kind> "<cmd>"` — parse with `shlex.split`; reject shell
  metacharacters `; | & $ \`` and newline before parsing; reject empty result.
- `sac profile clear <kind>` — clear override and re-detect from project.
- All subcommands support `--json` via `CLIJSONResponse` (stable contract 11).

Also fixed `docs/version_implementation_matrix.md` section heading from
"Active Forward Plan After v4.0.1" to "After v4.1.2".
