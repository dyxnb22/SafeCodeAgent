# v2.6.5 — Release Smoke-Test Workflow

## Summary

Adds a fast, deterministic `sac release smoke` command that validates the four
most important local release surfaces without replacing the full pytest suite.
No network access, no config mutation, no new dependencies.

## Changes

### `src/safecode/release/smoke.py` (new)

| Symbol | Description |
|---|---|
| `EXPECTED_POLICY_NAMES` | Frozenset of the five recognized policy names |
| `SmokeTestCase` | Frozen dataclass: `name`, `passed`, `detail` |
| `SmokeTestResult` | Dataclass with `cases`, `ok`, `failed` |
| `run_smoke_tests()` | Runs all four checks and returns a `SmokeTestResult` |
| `render_smoke_results(result)` | Renders results as plain text |
| `_check_import_version()` | Imports safecode and reads `__version__` |
| `_check_cli_version()` | Invokes `sac version` via Typer test runner |
| `_check_version_consistency()` | Calls `check_version_consistency()` |
| `_check_policy_names()` | Verifies `KNOWN_POLICY_NAMES` contains all five expected names |

### `src/safecode/cli_ops.py`

New `sac release smoke` command: runs `run_smoke_tests()`, prints rendered output,
exits with code 1 if any check fails.

### `tests/test_release_smoke.py` (new)

Five test classes, 24 focused tests covering individual check functions,
`run_smoke_tests()`, `render_smoke_results()`, and the CLI command.

## Smoke-test coverage

| Check | What it validates |
|---|---|
| `import_version` | `import safecode; safecode.__version__` is a non-empty string |
| `cli_version` | `sac version` exits 0 and includes the current version |
| `version_consistency` | `pyproject.toml` version == `safecode.__version__` |
| `policy_names` | `KNOWN_POLICY_NAMES` includes all five expected names |
