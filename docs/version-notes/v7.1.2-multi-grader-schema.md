# v7.1.2 Multi-Grader Schema

## Status

Implemented on `dev/v4.19` and tagged as `v7.1.2`.

## What Changed

- Added `LiveEvalGraderResult` as the structured grader record for live eval
  trials.
- Added `grader_results` to `LiveEvalResult.as_dict()`.
- Added `grade_live_eval_result()` with stable grader names:
  `outcome`, `validation`, `safety_invariants`, `scope_control`, and
  `reviewer_gate`.
- Wired the live eval runner to attach grader results to every trial outcome.

## Acceptance

- `uv run pytest tests/test_live_eval_mode.py::TestLiveEvalResultSchema tests/test_live_eval_mode.py::TestLiveEvalRunner -q`
- `uv run pytest tests/test_release_metadata.py tests/test_versions_json_sync.py -q`

## Notes

The graders are deterministic metadata over the existing run result. They do
not replace fixture success conditions or validation commands; they make eval
failures easier to compare across providers and later dashboard reports.
