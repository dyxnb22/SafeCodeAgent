# v4.24.1: github-read-tools

## Base
- Depends on: `v4.24.0`

## Completion Notes
- `src/safecode/agent/github_read_tools.py` (new):
  - `_validate_gh_name(value, field)`: validates owner/repo against `[a-zA-Z0-9._-]+` to prevent argument injection.
  - `_gh_available()`: checks `gh` CLI presence via `shutil.which`.
  - `_run_gh(args)`: runs `["gh", *args]` with `shell=False`, 30s timeout; returns `(success, output_or_error)`.
  - `_network_check(project_root)`: loads config, returns error if `network_enabled=False`.
  - `_read_issue_handler()` + `GITHUB_READ_ISSUE_SPEC`: `gh issue view N --repo owner/repo --json title,body,labels,state,number`.
  - `_read_pr_handler()` + `GITHUB_READ_PR_SPEC`: `gh pr view N --repo owner/repo --json title,body,state,reviewDecision,headRefName,baseRefName,number`.
  - `_read_file_handler()` + `GITHUB_READ_FILE_SPEC`: `gh api repos/owner/repo/contents/path [--field ref=...]`; decodes base64 `content` field; rejects `..` path traversal.
  - `register_github_read_tools(dispatcher, project_root)`: registers all three tools.
  - `redact_secrets()` applied to all outputs.
  - All subprocess calls use `shell=False` argv lists; no shell injection possible.

## Safety Invariants
- `owner`/`repo` validated against safe pattern; shell metacharacters rejected.
- All `subprocess.run` calls use `shell=False` (argv list). Zero shell injection surface.
- `network_enabled=False` (default) → blocked.
- `gh` missing → blocked with install hint.
- `.` path traversal in `github_read_file` → blocked.
- Auth via `GITHUB_TOKEN` env var or `gh auth status`; never written to disk.
- `redact_secrets()` applied to all tool outputs.
