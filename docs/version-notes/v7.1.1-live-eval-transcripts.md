# v7.1.1 — Live Eval Transcript Artifacts

v7.1.1 adds opt-in transcript artifacts for live eval trials.

## Changed

- Added `LiveEvalRunner(..., transcript_dir=...)`.
- Added `save_live_transcript()` for redacted JSON transcript files.
- Added `sac eval --mode live --transcripts`.
- Added `transcript_path` to `LiveEvalResult`.

## Transcript Contents

Each artifact records:

- fixture metadata and eval suite
- provider/model
- user goal
- validation commands
- trajectory milestones
- final outcome metrics

## Safety

- Transcript text is redacted before JSON serialization.
- Transcript writing is opt-in.
- Default CI/mock runs do not write extra artifacts.

```bash
uv run pytest tests/test_live_eval_mode.py::TestLiveEvalTranscripts -q
```
