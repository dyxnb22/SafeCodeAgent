# v2.9.0 — agent-loop-fixture-expansion

## Summary

Expanded loop-mode eval fixtures from two to six realistic local scripted scenarios.
Added typed failure categories (`LoopFailureCategory`, `ClassifiedLoopFailure`) so
fixture failures carry machine-readable reason codes rather than plain strings.
`RecoverableContractFailure` type added to `loop_runner.py` (used by v2.9.1 bounded
retry); `ScriptedStep.first_fail_recoverable` flag added with default `False` for
backward compatibility.

## New fixtures

| Name | Description | Expected outcome |
|---|---|---|
| `docs-edit` | (existing) Read docs, propose safety note patch | pending patch |
| `python-function-fix` | (existing) Read utils.py, fix multiply function | pending patch |
| `config-update-fix` | Read `.sac/config.toml`, add missing `timeout_seconds` | pending patch |
| `test-assertion-fix` | Read `tests/test_math.py`, correct off-by-one assertion | pending patch |
| `shell-readonly-check` | Read README, stop for user (no write) | stop for user |

## New types

- `LoopFailureCategory(str, Enum)`: `contract_violation`, `patch_missing`,
  `patch_content_mismatch`, `loop_error`, `unknown`
- `ClassifiedLoopFailure(frozen dataclass)`: `category`, `reason`, `as_dict()`
- `RecoverableContractFailure(frozen dataclass)`: `step`, `method`, `message`
  (returned by `ScriptedLLMClient` when `first_fail_recoverable=True`; handled
  by `AgentLoop` in v2.9.1)
- `LoopEvalResult.classified_failures: list[ClassifiedLoopFailure]` — new field,
  backward-compatible (default empty list)

## Files changed

- `src/safecode/eval/loop_runner.py` — 4 new fixtures, failure classification,
  `RecoverableContractFailure`, `ScriptedStep.first_fail_recoverable`
- `tests/test_agent_loop_fixture_expansion.py` — 31 new tests

## Acceptance

- `sac eval --mode loop` runs all six fixtures locally with exit 0.
- No real provider calls.
- Failures report typed reason categories via `classified_failures`.
- 31 focused tests pass: fixture loading, execution count, typed failure categories.
