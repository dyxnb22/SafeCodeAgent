# v3.6.3 — Per-Session HTML Report (report-html)

## Summary

Adds `sac report html --session <id>` that renders a deterministic, self-contained
HTML page from the existing journal data for one agent session.  No external network
assets.  Secrets are redacted before rendering.  Missing or empty sessions produce
a human-readable page rather than an error.  The existing `sac report` (Markdown)
command is preserved for backward compatibility.

## Key Additions

- `src/safecode/report/session_html.py` (new).
- `render_session_html(session_id, project_root) -> SessionHtmlReport`: reads the
  `AgentJournalStore` for the given session, redacts secrets via `redact_secrets()`,
  and returns a `SessionHtmlReport(session_id, html, event_count, found)`.
- Output is deterministic (byte-identical for the same inputs) and self-contained
  (no `http://`/`https://` references).
- Invalid session IDs handled gracefully (error HTML page, `found=False`).
- Missing or empty sessions handled gracefully (`found=False`).
- HTML is properly escaped (`html.escape` on all journal message content).
- `sac report html --session <id>` prints HTML to stdout.
- `sac report html --session <id> --output <path>` writes to a file.
- `sac report` (no subcommand) still renders Markdown — backward compat preserved.
- `src/safecode/cli_ops.py`: `report_app` Typer group with `invoke_without_command=True`
  replaces the flat `ops_app.command("report")`; callback renders Markdown when no
  subcommand given.
- `src/safecode/cli.py`: imports and registers `report_app` as `sac report`.
- 30 new tests in `tests/test_report_html.py`.

## Safety Invariants

- Audit, journal, and redaction behaviour unchanged.
- No external network assets in any rendered HTML.
- All journal content HTML-escaped before embedding.
- `redact_secrets()` applied to every journal message before rendering.
