# v3.5.1 — VS Code Extension Skeleton (repo-side manifest)

## Summary

Extends `ide/manifest.py` so the manifest describes launching the JSON-RPC API
and opening pending diff targets. No external extension repo is created since
this repository does not have that structure; the manifest is the skeleton.

## Changes

- `src/safecode/ide/manifest.py`: adds `jsonrpc_transport` section with
  `launch_command`, `protocol`, `transport`, `contract_version`,
  `supported_methods`, and experimental note.
  Adds `pending_diff_targets` section with `open_diff_command`.
  Adds `safecode.apiJsonrpc` command entry.
  Exports `_JSONRPC_CONTRACT_VERSION = "1"`.

## Invariants

- `render_manifest()` is deterministic (byte-identical for repeated calls).
- Manifest is valid JSON.
- `jsonrpc_transport.launch_command` is `["sac", "api", "jsonrpc"]`.
- `jsonrpc_transport.supported_methods` matches `_SUPPORTED_METHODS` from `api/jsonrpc.py`.
- All existing commands (`safecode.ask`, `safecode.edit`, etc.) are preserved.

## Experimental label

IDE bridge surfaces remain EXPERIMENTAL.
