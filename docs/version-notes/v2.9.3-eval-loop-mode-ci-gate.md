# v2.9.3 — eval-loop-mode-ci-gate

## Summary

Adds the loop eval suite to CI as a separate advisory job so scripted agent-loop
evidence is visible on pushes and pull requests before becoming a blocking gate.

The job uses local scripted fixtures only. It does not require live provider
credentials or network-backed LLM calls.
