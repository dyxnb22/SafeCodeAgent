# v3.2.6 — Providers Docs + Provider Contract Promotion

## Summary

Promotes the LLM provider layer to a documented, snapshot-tested stable contract.
Adds `docs/providers.md` as the full provider reference, extends `docs/public-contracts.md`
with section 9 (LLM Provider Contract), and adds a machine-readable snapshot at
`tests/snapshots/contracts/provider_contract_schema.json`.

No runtime behavior changes. All v3.2.5 tests pass without modification.

## New Files

- `docs/providers.md`: Full provider reference covering supported keys, config fields,
  retry semantics, structured output validation, streaming, cost accounting, fan-out/fallback,
  live CI lane, and experimental features.

- `tests/snapshots/contracts/provider_contract_schema.json`: Machine-readable contract snapshot
  with `supported_provider_keys`, `config_fields` (with defaults), `retry_semantics`,
  `streaming_semantics`, `structured_output_validation`, `cost_accounting`, `fanout_config`,
  `experimental_features`, and `live_ci_lane`. Sorted keys, no prose, no timestamps.

- `tests/test_provider_contract_snapshot.py`: 66 snapshot tests across 10 test classes:
  file integrity, top-level fields, config fields, retry semantics, streaming semantics,
  structured output, cost accounting, fan-out, experimental features, live CI lane, and
  live code import/interface checks.

## Modified Files

- `docs/public-contracts.md`: Added section 9 "LLM Provider Contract" before Experimental Surfaces.
  References `docs/providers.md`, lists supported providers, and documents retry/validation/fan-out
  invariants.

- `README.md`: Added link to `docs/providers.md` alongside the existing `docs/public-contracts.md` link.

## Stable Contract Invariants (from snapshot)

- **Supported providers**: `mock`, `openai`, `openai-compatible`, `anthropic`.
- **Retry**: 429 and 503 retried; `URLError` retried; `PermissionError`, `ValueError`, and
  `RecoverableContractFailure` never retried.
- **Fan-out trigger**: `RuntimeError` only; `PermissionError` and `ValueError` propagate.
- **Structured output**: soft failures → `RecoverableContractFailure`; wrong contract type → `ValueError`.
- **Streaming cancel**: fail-closed; partial output discarded; session state not mutated.
- **Cost accounting**: `SessionCostAccumulator` persists to `.sac/sessions/<id>/cost.json`; `cost_usd` always null until pricing is wired.

## Experimental (not promoted)

- Prompt caching headers (`cache_control`)
- Additional cloud providers beyond the four tested keys
- Provider-specific advanced options (tool use, vision, extended system prompts)
- Live CI lane blocking gate (currently advisory)
- Streaming fan-out mid-stream recovery
