# v2.5.4 — Performance Budgets

## Summary

Adds lightweight, deterministic performance budget telemetry for eval/replay
runs.  No new runtime dependencies introduced.

## New Module

`src/safecode/trace/budget.py` — performance budget models and helpers.

### Public API

- **`PerformanceBudget`** (frozen dataclass): `context_size_bytes` (int),
  `total_command_duration_ms` (float), `llm_latency_ms` (float | None),
  `disk_growth_bytes` (int).  All fields default to zero/None.
- **`PerformanceBudget.as_dict()`**: returns a deterministic,
  JSON-serializable `dict`.  `total_command_duration_ms` is rounded to 3
  decimal places.  `llm_latency_ms` is `None` when no real LLM was invoked.
- **`compute_context_size(snapshot)`**: returns total UTF-8 encoded byte count
  across all file contents in a `{path: content}` snapshot.
- **`compute_disk_growth(before, after)`**: returns net bytes added between
  two snapshots (never negative; returns 0 when disk usage shrank).

## Updated Files

- `src/safecode/trace/__init__.py` — exports `PerformanceBudget`,
  `compute_context_size`, `compute_disk_growth`.
- `src/safecode/eval/runner.py` — integrates budget measurement into
  `TaskReplayRunner`:
  - `ReplayResult.performance_budget: PerformanceBudget | None = None` —
    new backward-compatible field (defaults to `None`; existing call sites
    work unchanged).
  - `_run_in_workspace()` computes and attaches a `PerformanceBudget` with:
    - `context_size_bytes` from the initial workspace snapshot.
    - `total_command_duration_ms` summing setup and validation command wall
      time via `time.perf_counter()`.
    - `llm_latency_ms = None` (no real LLM in `TaskReplayRunner`).
    - `disk_growth_bytes` computed from before/after snapshots.
  - `_error_result()` leaves `performance_budget = None` (workspace was never
    fully materialised).

## Design decisions

- **No new dependencies**: only stdlib `time.perf_counter()` added.
- **Deterministic and snapshot-friendly**: `as_dict()` always produces the
  same output for the same inputs; `llm_latency_ms` is an explicit `None`
  placeholder rather than omitted to keep the schema stable.
- **Backward-compatible**: `ReplayResult.performance_budget` defaults to
  `None`; all existing `ReplayResult` construction sites work without change.
- **Fail-safe**: `_error_result()` correctly leaves the budget unset when
  workspace materialisation fails.

## Test Coverage

40 tests in `tests/test_performance_budgets.py` covering:
- `PerformanceBudget` default and explicit construction.
- `as_dict()` shape, JSON serializability, rounding, and determinism.
- `compute_context_size`: empty snapshot, ASCII, multi-byte, multi-file.
- `compute_disk_growth`: equal, added, removed, mixed snapshots.
- `ReplayResult.performance_budget` default None (backward compat).
- `TaskReplayRunner` integration: budget populated on success, context size
  matches initial workspace, disk growth tracked, `llm_latency_ms` is None,
  command duration is non-negative float, `_error_result` leaves budget None.
- Frozen dataclass immutability.
