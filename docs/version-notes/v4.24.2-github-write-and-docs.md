## Safety Invariants
- Both write tools `requires_approval=True` — agent always pauses before executing.
- `audit_event_type="tool_call_write"` — write tool calls logged distinctly from reads.
- Branch name validated; leading `-` and shell metacharacters blocked.
- `subprocess.run` uses `shell=False` argv list; no injection surface.
- `force` push must be explicitly `True` in input; no default force.
- `redact_secrets()` on all outputs.
