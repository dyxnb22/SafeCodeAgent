# v3.7.1 — setup wizard + progress indicator

## Summary

- **T-3.7.1-A `sac setup --wizard`** (`src/safecode/cli.py`): new `--wizard` flag on the
  existing `sac setup` command. Non-TTY (CI/pipe) exits 0 with a static configuration
  template and does not prompt. TTY mode walks provider/model/policy interactively:
  - Switching away from `mock` requires explicit confirmation.
  - Network defaults off; two confirmations required to enable.
  - If the requested policy is less restrictive than the current user-level policy,
    the stricter policy is silently preserved (existing `_stricter_policy` logic).
  - Cancelling at the final confirm does not write any files.
  - 14 new tests in `tests/test_setup_wizard.py` (plus 5 pre-existing v2.3.1 tests kept).

- **T-3.7.1-B progress indicator** (`src/safecode/cli_progress.py`): lightweight TTY-aware
  progress utilities — `cli_status(message)` context manager (Rich spinner on TTY, silent on
  non-TTY) and `StepCounter(total)` (prints `[n/N] label` on TTY, zero bytes on non-TTY).
  20 new tests in `tests/test_cli_progress.py`.

## Safety invariants preserved

- Wizard refuses to write a config weaker than the current user-level policy.
- Network requires explicit double-confirmation to enable.
- Non-TTY mode never prompts; exits cleanly with a static template.
