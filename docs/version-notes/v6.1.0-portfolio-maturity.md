# v6.1.0 — Portfolio Maturity Cut

v6.1.0 is an additive product maturity release after the v6.0.0 stable-contract
cut. It does not promote new public contracts. It turns the project from a
stable safety runtime into a stronger resume/demo artifact with real provider
evidence and deeper developer workflow coverage.

## What Changed

- Live eval now runs the full proposal -> apply -> success-condition loop in a
  temporary workspace.
- OpenAI-compatible patch generation now asks for the structured
  `{"type":"patch","patch_text":"..."}` contract and extracts the SafeCode
  SEARCH/REPLACE patch envelope before parser validation.
- DeepSeek live eval was run with `deepseek-v4-flash`; two Python fixtures
  passed and the redacted result was recorded in
  `docs/demo/live-eval-summary.md` and `tests/snapshots/live_eval/latest.json`.
- Added a realistic multi-file todo-service demo under `examples/realistic-demo/`.
- Added project hook stages: `before_command`, `after_edit`, `after_test`, and
  existing `after_apply`, all routed through command policy and audit metadata.
- Added diagnostics-aware context collection for bounded pytest, TypeScript,
  and Go diagnostics before edit proposals.
- Updated README/status/resume docs for the v6.1.0 portfolio baseline.
