# v3.6.2 — OTel Exporter (otel-exporter)

## Summary

Adds an optional OpenTelemetry exporter for runtime events and agent steps.
Disabled by default; enabled via `SAFECODE_OTEL_EXPORTER=<otlp_endpoint>`.
If the `opentelemetry-api`/`opentelemetry-sdk` packages are not installed, the
exporter fails closed with an honest `RuntimeWarning` diagnostic and no telemetry
is emitted.  OTel remains experimental and optional.

## Key Additions

- `src/safecode/otel/__init__.py` and `src/safecode/otel/exporter.py` (new).
- `OtelExporter`: no-op by default; `OtelExporter.from_env()` reads
  `SAFECODE_OTEL_EXPORTER`; disabled when env var is absent or empty.
- `OtelExportResult(frozen dataclass)`: `exported: bool`, `skipped_reason: str | None`.
- `OtelExporter.is_enabled()`: authoritative; always `False` unless env var set and
  OTel SDK available.
- `OtelExporter.export_event(span_name, message, attributes)`: never raises; returns
  `OtelExportResult(exported=False, skipped_reason="disabled")` when disabled.
- Missing `opentelemetry-api`/`opentelemetry-sdk` → `RuntimeWarning` + disabled.
- Missing `opentelemetry-exporter-otlp-proto-http` → `RuntimeWarning` + disabled.
- Endpoint string never appears in warning or error text.
- `SAFECODE_OTEL_EXPORTER` must not be set in the test environment; verified by test.
- 36 new tests in `tests/test_otel_exporter.py`.

## Safety Invariants

- No telemetry emitted by default or in tests.
- Fails closed on any OTel initialisation error.
- OTel dependency is optional; not added to `pyproject.toml` required dependencies.
- Audit/journal/redaction behaviour is unchanged.
