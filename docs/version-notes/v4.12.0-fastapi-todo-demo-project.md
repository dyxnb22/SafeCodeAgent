# v4.12.0 - FastAPI Todo Demo Project

Adds `examples/fastapi-todo/`, a small FastAPI todo API outside the SafeCode package import path. The example includes `GET /todos`, `POST /todos`, an in-memory store, four baseline endpoint tests, `.sac/project_profile.json`, and README instructions for `uv sync --extra examples`, `pytest -q`, and the intended future task: `sac agent run "add a DELETE /todos/{id} endpoint with a passing test"`.

Validation: `uv sync --extra examples`; `PYTHONPATH=src python3 -m pytest -q tests/test_example_fastapi_todo.py`; full `PYTHONPATH=src python3 -m pytest -q`.

Safety and contract note: the example is demo code only, not packaged as `safecode` code. No stable contract is promoted.
