## Completion Notes
- `src/safecode/agent/multi_tool_turn.py` (new): `MultiToolTurnRunner` class.
  - `dispatch_calls(calls)`: dispatch a list of NativeToolCalls via NativeToolDispatcher;
    cap at `max_turn_tools` (default 20); return `MultiToolTurnResult` with per-call records,
    observations, cap_hit flag, and `context_block()` for next-prompt injection.
  - `run_turn(initial_calls, *, llm_next_fn, context)`: full turn loop — dispatch, feed
    results back via `llm_next_fn`, repeat until model returns None (done) or cap hit.
  - `identity_sequence(calls)`: hashable tuple for stuck-loop detection across turns.
  - Input summaries and output snippets are redacted before recording.
- **Bug B9 fix** (`agent/loop.py`): `_abort_if_stuck_tool_intent` now tracks
  `has_current_task`; when outside task scope, emits `RuntimeWarning` but does NOT abort
  (preserves existing taskless-session behaviour); inside task scope, aborts as before.
  RuntimeLogger entry emitted in both cases, so stuck-loop is always observable.
- No stable contract promoted.
