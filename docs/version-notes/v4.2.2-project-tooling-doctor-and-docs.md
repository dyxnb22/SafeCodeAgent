## Tasks

### T-4.2.2-A doctor-missing-deps

`Doctor._project_tooling_diagnostics()` added to `src/safecode/doctor.py`:

- Called from `run_diagnostics()` after sandbox promotion diagnostics.
- If no profile: single `project_tooling` SKIP diagnostic with "run sac profile detect" hint.
- If profile exists: reports one diagnostic per kind (test/lint/typecheck/build):
  - PASS: detected, binary available.
  - SKIP: not detected (`None`) or `missing_dependency=True`.
  - **Missing tool → SKIP, not FAIL** — does not alarm users who don't use that tool.
  - SKIP message for missing tool includes binary name and `sac profile set <kind>` hint.
- Diagnostic names: `project_tooling_<kind>`.
- Preserves diagnostic substrate contract: name, status (enum), message, hints, metadata.
