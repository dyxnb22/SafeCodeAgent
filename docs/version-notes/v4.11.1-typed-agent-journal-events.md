# v4.11.1 - Typed Agent Journal Events

## Summary

Persists typed step and typed result events in the existing
`AgentJournalStore` at `.sac/agent_journals/<session_id>.jsonl`. The journal
extension is additive: legacy journal event shapes and renderers continue to
work while `sac status --json` can read the latest plan and typed result.

## Changed Files / Modules

- `src/safecode/state/journal.py`: adds `typed_step` / `typed_result` event
  types, record helpers, and tolerant read helpers for latest plan and last
  typed result.
- `src/safecode/agent/loop.py`: records typed step/result projections alongside
  existing journal events.
- `src/safecode/cli_status.py`: includes typed agent plan/result context in
  JSON status output.
- `docs/mvp-user-guide.md`: documents the typed-step journal path under the
  existing task-first flow.
- `tests/test_agent_journal_typed_events.py` and `tests/test_agent_journal.py`:
  round-trip, redaction, corrupt-line tolerance, ordering, and legacy renderer
  compatibility.

## Tests Run

Focused local evidence: `PYTHONPATH=src python3 -m pytest -q tests/test_agent_journal_typed_events.py tests/test_agent_journal.py tests/test_agent_loop_typed_steps.py`.

Full-suite local evidence: `PYTHONPATH=src python3 -m pytest -q`.

## Safety / Contract Note

No new stable contracts promoted. Typed journal events are EXPERIMENTAL,
additive, redacted, and stored only through the existing `AgentJournalStore`.
They are not an audit substitute.
