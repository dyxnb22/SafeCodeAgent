# v2.8.6 — CLI Sandbox Module Split

## Summary

Split `src/safecode/cli_sandbox.py` by command ownership while preserving exact CLI behavior. No command was renamed, no argument was reordered, and no safety gate was weakened.

## Changes

### New modules

- `src/safecode/cli_sandbox_status.py` — `sandbox_status`, `sandbox_plan` (242 LOC)
- `src/safecode/cli_sandbox_proposal.py` — `sandbox_propose`, `sandbox_pending`, `sandbox_discard`, `sandbox_execute`, `sandbox_approve`, `sandbox_approvals`, `sandbox_revoke`, `sandbox_preflight` (267 LOC)
- `src/safecode/cli_sandbox_executions.py` — `executions_app` (callback, stats, prune), `sandbox_last_execution`, `sandbox_execution_show` (239 LOC)

### Modified

- `src/safecode/cli_sandbox.py` — rewritten as thin Typer registry (42 LOC); imports functions from sub-modules and registers them on `sandbox_app`
- `tests/test_cli_output_honesty.py` — updated mock patch targets to `cli_sandbox_status.*` (from `cli_sandbox.*`)
- `tests/test_tool_call_gate.py` — updated `test_cli_sandbox_imports_gate` to check `cli_sandbox_proposal` (where `ToolCallGate` is now imported)

## Acceptance

- No command rename or argument reorder.
- `sac sandbox --help` remains compatible.
- Each new command module stays below 320 LOC.
- All 434 sandbox tests pass.
- Full regression: 2148 passed, 1 warning.
