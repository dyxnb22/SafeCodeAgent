# v4.18.0 - Diff Rendering in Shell + Per-Patch Undo

## Summary

Adds Rich syntax-highlighted diff preview inline in `sac shell /apply`,
per-patch checkpoint granularity with ID-based rollback, and checkpoint
listing.

## Changes

- `checkpoint/manager.py`: `rollback_by_checkpoint_id()` restores a specific
  checkpoint. `list_checkpoints()` returns all checkpoints newest-first.
  `_restore_checkpoint()` factored out from `rollback_last()`. `_load_metadata()`
  loads a checkpoint by explicit ID.
- `agent/orchestrator.py`: `rollback_checkpoint(checkpoint_id)` and
  `list_checkpoints()` wrapper methods with audit events.
- `cli_core.py`: `sac rollback` gains `--checkpoint <id>` for per-patch
  restore and `--list` for viewing available checkpoints. Error message
  updated to guide users to the new flags. `--last` unchanged.
- `cli_shell.py`: `_slash_apply()` now renders diff inline via
  `Rich Syntax("diff")` before asking for confirmation, matching the
  batch `sac apply` UX.

## Tests

- `tests/test_per_patch_undo.py`: 7 tests covering empty list, create+list,
  rollback by ID, rollback by not-found ID, rollback_last still works,
  orchestrator list_checkpoints, and orchestrator rollback_checkpoint.
