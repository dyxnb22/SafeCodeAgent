# v3.0.0 - Public Contract Stabilization

## Summary

Stable local safety runtime release. Documents and explicitly labels the v3.0 supported
contracts and experimental surfaces. No broad new features; all v2.9.9 snapshot tests pass.

## Changes

- `docs/public-contracts.md`: New document describing the 8 stable local safety contracts
  and 6 explicitly experimental surfaces.
- `README.md`: Added link to `docs/public-contracts.md`.
- Version bumped to `3.0.0` in `pyproject.toml` and `src/safecode/__init__.py`.

## Stable Contracts (v3.0)

1. Config precedence and lowering rules (`SafeCodeConfig`)
2. Pending patch format (`PatchProposal`, `PatchBlock`)
3. Audit event hash-chain behavior (`AuditEvent`, `AuditLogger`, `AuditAnchorStore`)
4. Sandbox approval and result lifecycle (`SandboxExecutionProposal`, `SandboxExecutionApproval`, `SandboxExecutionResultRecord`)
5. Local tool registry shape (`ToolSpec`, `ToolRegistry`, `REGISTRY_SCHEMA_VERSION`)
6. Deterministic eval trace format (`LoopStepTrace`, `LoopEvalTrace`, `build_loop_eval_trace`)
7. Recommended CLI workflows (`sac setup/quickstart/ask/edit/apply/rollback/run/doctor/version`)
8. Hidden/internal release command policy (`sac release signoff/checklist/check/smoke/meta` hidden but callable)

## Experimental Surfaces

- `SafeCodeLocalAPI` beyond `ask()` and `report()`
- OpenAI-compatible live provider behavior
- MCP schema shim
- Subagent payload evolution beyond v1 read-only bounded findings
- TUI (`sac tui dashboard`)
- IDE bridge (`sac ide ...`)
