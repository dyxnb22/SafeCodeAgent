# v4.5.0 - local commit and dirty-tree guard

## Status

Implemented. All v4.5.0 surfaces are EXPERIMENTAL. No stable public contracts were promoted.

## What changed

- Added `src/safecode/git/local.py` with local-only Git helpers that call `subprocess.run(["git", ...], shell=False)`.
- Added experimental `sac commit [--message-from-task] [--branch <name>] [--include-task-summary] [--json]`.
- `sac commit` stages only files associated with the CURRENT task through applied checkpoint/audit metadata and fails closed when task files cannot be determined.
- Added dirty-tree guards for `sac apply` and `sac commit`.
- Dirty-tree guards refuse unrelated tracked/staged changes, ignore untracked files outside touched directories, and block untracked files inside touched directories.
- Added explicit `--allow-unrelated-changes` override for guarded paths.

## Safety notes

- Local only: no push, fetch, pull, or remote operations.
- Default refusal paths do not modify files or staging.
- Dirty-tree refusal is audited where the existing audit logger is available.
- `PatchProposal` and `AuditEvent` field sets are unchanged.
