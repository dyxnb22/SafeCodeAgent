# v2.6.12 — Version-Note Index Validation

## Summary

Hardens the release metadata index so version-note files are not only present,
but also correctly headed and unique for the current version.

## What changed

- `src/safecode/release/metadata.py`: detects duplicate version-note files for
  the same version and checks that the first Markdown heading mentions `vX.Y.Z`.
- `sac release meta`: renders heading and duplicate-note status.
- `sac release preflight`: inherits the stricter metadata gate.
- `tests/test_release_metadata.py`: adds focused filesystem-only validation
  coverage for headings and duplicates.
