# v4.5.2 - task diff and local git docs

## Status

Implemented. All v4.5 surfaces remain EXPERIMENTAL. No stable public contracts were promoted.

## What changed

- Added `sac diff --task [<task_id>] [--json]`.
- Omitted task id resolves to CURRENT.
- Missing tasks and tasks without files return a deterministic empty result.
- Diff output is read-only: it does not stage, commit, or write project files.
- Diff output combines applied task file changes relative to HEAD with a pending patch preview where available.
- Diff content is redacted before display or JSON rendering.
- README Core Commands now documents `sac commit`, `sac branch new`, `sac diff --task`, and the dirty-tree guard.
- MVP guide now documents the local delivery flow: task -> edit/fix -> apply -> diff/commit -> optional branch.
- Troubleshooting now covers dirty unrelated changes, rollback after committed apply, branch creation refusal, and unknown task files for commit/diff.

## Safety notes

- `sac diff --task` is read-only and local-only.
- v4.5 commands are not stable public contracts.
- No git push or remote operation was added.
- No `PatchProposal` or `AuditEvent` field sets changed.
