# v4.15.2 - Keychain and Env-only Credentials

## Summary

Makes `sac provider add` default to env var usage for API keys. Literal `--api-key`
values now require `--store user-config` or `--store keychain` to persist.
Adds system keychain backend (macOS Keychain / Linux Secret Service) via keyring.

## Changes

- `sac provider add --api-key <key>` now requires `--store {user-config|keychain}`.
- `--store keychain`: stores API key in system keyring via keyring library.
- `sac provider rm`: cleans up matching keychain entries.
- `sac doctor`: reports `credential_storage` diagnostic showing env/keychain/user-config/missing.
- New module: `src/safecode/security/keychain.py`.

## Tests

- `tests/test_provider_keychain_backend.py`: 8 tests covering --store requirement,
  keychain backend (mocked), credential_storage doctor, and env var paths.

All existing tests pass. No stable contract changes.
