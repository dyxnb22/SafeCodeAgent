# v4.19.0: task-stats

## Base
- Depends on: `v4.18.2`
- Plan: `docs/version-plans/v4.19.0-task-stats.md`

## Completion Notes
- Added `sac task stats [--task <id>] [--json]` (EXPERIMENTAL) to `src/safecode/cli_task.py`.
- Private `_histogram()` helper builds deterministic sorted-key histograms; skips `None` by default.
- Reads `TaskState`, `TaskBudgetStore`, and `MemoryFacade.read_pinned_files()` — pure reads, no mutation.
- Output fields: `task_id`, `status`, `created_at`, `updated_at`, `goal` (redacted),
  `iterations.{total, last_iteration_index, last_event, by_event, by_status, by_failure_category}`,
  `pending_patch_id`, `last_command` (redacted), `audit_trace_count`, `budget`, `pinned_files.count`,
  `experimental: true`.
- JSON envelope uses `command="task stats"`, `status="success"` (stable contract 11).
- Closed tasks are readable (read-only; no mutation restriction).
- No stable contract promoted; all v4 surfaces remain EXPERIMENTAL.
