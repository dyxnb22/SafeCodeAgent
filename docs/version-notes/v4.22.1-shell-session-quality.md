# v4.22.1: shell-session-quality

## Base
- Depends on: `v4.22.0`
- Plan: `docs/version-plans/v4.20-to-v5.0-product-roadmap.md` (v4.22.1 section)

## Completion Notes
- **Bug B10 fix** (`cli_shell.py`): `/clear` now calls `AgentSessionStore(project_root).clear()`
  to reset the live agent session state; no longer just returns a string without side effects.
- **Bug B11 fix** (`cli_shell.py`): `_read_line()` on EOF (both TTY `EOFError` and non-TTY
  empty readline) now prints `\n[exiting shell]` before returning `None`, consistent across modes.
- **Prompt** (`cli_shell.py`): `_shell_prompt(turn)` returns `sac[N]>` with turn counter;
  `_read_line` accepts `turn` param; `run_shell` increments `turn_count` per iteration.
- **New `/undo` command**: calls `CheckpointManager.rollback_last()` to undo the most recent
  write-tool checkpoint; reports checkpoint id and restored paths.
- **New `/history` command**: reads `ShellSessionStore.list_sessions()` and prints the last
  10 turns of the newest session.
- **New `/tools` command**: lists all seven registered native tool specs (read_file, list_files,
  search_files, grep_files, edit_file, write_file, run_command) with approval annotations.
- `_SLASH_COMMANDS` and `_SHELL_HELP` updated to include `/undo`, `/history`, `/tools`.
- No stable contract promoted.

## Tests
