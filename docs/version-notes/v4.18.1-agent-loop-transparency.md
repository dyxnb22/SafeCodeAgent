# v4.18.1 - Agent-Loop Transparency

## Summary

Adds Rich Status spinner to `sac agent run` and `sac shell --agentic` for
real-time step progress display. AgentLoop.run() gains an optional `on_step`
callback for external observers.

## Changes

- `agent/loop.py`: `AgentLoop.run()` accepts optional `on_step` callback
  (Callable[[AgentStepResult], None]) called after each step. Callback
  exceptions are silently caught so they never abort the loop. Import
  of `Callable` added.
- `cli_shell.py`: `_run_agentic_shell()` uses `rich.status.Status` spinner
  with "Agent loop running..." during loop execution in TTY mode. Step
  updates collected and included in JSON output. Banner updated to v4.18.
- `cli_agent.py`: `agent_run` uses Rich Status spinner in TTY non-JSON
  mode when max_steps > 1, providing real-time feedback that the agent
  is working.

## Tests

- `tests/test_agent_loop_transparency.py`: 5 tests covering on_step
  callback invocation, backward compatibility without callback,
  exception isolation, per-step call count, and agent_run smoke.
- Updated FakeLoop mocks in `test_cli_agent_run.py`, `test_cli_shell.py`,
  `test_resume_agentic.py`, and `test_validation_loop.py` to accept the
  new `on_step` keyword argument.
