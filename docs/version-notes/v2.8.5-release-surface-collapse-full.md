# v2.8.5 Release Surface Collapse Full

## Summary

Collapses the `sac release` help surface to only the three supported commands
(`preflight`, `bump`, `changelog`). The five internal/advanced helpers
(`checklist`, `check`, `smoke`, `meta`, `signoff`) are now hidden from
`sac release --help` but remain fully callable for compatibility.

`sac release signoff` now emits a `RuntimeWarning` pointing users to
`sac release preflight`. The rendered output already carried the deprecated
notice since v2.7.9; the warning makes it machine-catchable.

`docs/install-update.md` updated to note that the internal helpers are hidden
from help output. `sac release checklist` is noted as a planning helper, not
a release gate.

## Changed Files

- `src/safecode/cli_ops.py` — `hidden=True` on checklist/check/smoke/meta/signoff; `RuntimeWarning` in signoff handler; `import warnings`
- `docs/install-update.md` — helpers section clarified as hidden from `--help`; signoff noted as deprecated
- `tests/test_release_surface_collapse_full.py` — 25 focused tests
