# v2.8.8 Shell Exit Code Honesty

## Summary

`sac run` now returns the shell runner's exit codes directly:

- `125` — approval required (medium-risk command without `--yes` or stored approval)
- `126` — policy blocked (high-risk or disallowed command)

These codes were already returned by `ShellRunner.run()` since the command policy
was introduced. v2.8.8 makes them documented and tested, and adds a one-cycle
legacy opt-out for scripts that relied on exit code `1` for all blocked cases.

**Legacy opt-out:** Set `SAFECODE_RUN_LEGACY_EXIT_CODE=1` to get exit code `1`
for all non-executed cases. This opt-out will be removed in a future version.

## Changed Files

- `src/safecode/cli_core.py` — `import os`; legacy opt-out branch before `raise typer.Exit`
- `docs/install-update.md` — new section documenting 125/126 codes and the legacy env var
- `tests/test_shell_exit_code_honesty.py` — 13 focused tests
