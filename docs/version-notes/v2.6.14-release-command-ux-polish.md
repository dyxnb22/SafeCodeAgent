# v2.6.14 — Release Command UX Polish

## Summary

Standardizes release command output around `Status: PASS/FAIL`, consistent next
steps, and shared exit-code semantics.

## What changed

- `src/safecode/release/ux.py` (new): shared helpers for status labels, exit
  codes, headers, and next-step rendering.
- Release renderers now include a common status line and next-step section.
- Release CLI failure exits now use the shared `exit_code()` helper.
- `tests/test_release_ux.py`: focused coverage for the shared UX helpers.
