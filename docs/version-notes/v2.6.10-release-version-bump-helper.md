# v2.6.10 — Release Version Bump Helper

## Summary

Adds a small helper that updates all canonical version locations together to prevent
manual bump drift across `pyproject.toml`, `src/safecode/__init__.py`, and the install
polish test.

## What changed

- `src/safecode/release/bump.py` — new module with:
  - `bump_versions(new_version, ...)` — updates `pyproject.toml` `[project].version`,
    `src/safecode/__init__.py` `__version__`, and
    `tests/test_install_update_polish.py` version assertion atomically.
  - `render_bump_result(result)` — human-readable output.
  - Validates `X.Y.Z` format; rejects invalid strings before touching any file.
  - Accepts `dry_run=True` to preview without writing.
  - Missing optional files are skipped (reported in `skipped_files`), not errors.
- `src/safecode/cli_ops.py` — adds `sac release bump VERSION [--dry-run]` command.
- `tests/test_release_version_bump.py` — 22 focused tests covering happy path,
  dry-run, invalid version, missing files, render, and CLI integration.
- `docs/version-notes/v2.6.10-release-version-bump-helper.md` — this file.

## Usage

```bash
# Preview what would be changed
sac release bump 2.6.11 --dry-run

# Apply the bump
sac release bump 2.6.11
```

The helper does **not** commit or tag — that remains a manual step after verification.
