# v2.6.3 — Release Checklist Command Polish

## Summary

Extends the `sac release` command group with a new `sac release check` command
that reports the local release readiness state: package version, runtime version,
version consistency, working-tree cleanliness, and plain-text suggested next steps.

The command does **not** run tests itself and does not claim tests passed.

## Changes

### `src/safecode/release/check.py` (new)

| Symbol | Description |
|---|---|
| `ReleaseCheckResult` | Frozen dataclass: `package_version`, `runtime_version`, `version_consistent`, `version_message`, `tree_clean`, `tree_detail`, `next_steps`, `ok` |
| `run_release_check(project_root, pyproject_path, runtime_version)` | Runs version consistency + git working-tree check; returns `ReleaseCheckResult` |
| `render_release_check(result)` | Renders result as plain text for CLI output |
| `_check_tree_clean(project_root)` | Runs `git status --porcelain`; returns `(bool|None, detail)` |

### `src/safecode/cli_ops.py`

New `sac release check` command: calls `run_release_check(cwd)`, prints the
rendered output, exits with code 1 on failure.

### `tests/test_release_checklist_polish.py` (new)

Three test classes covering `run_release_check`, `render_release_check`, and the
`sac release check` CLI command (15 focused tests).
