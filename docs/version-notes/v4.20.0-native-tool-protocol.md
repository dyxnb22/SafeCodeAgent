# v4.20.0: native-tool-protocol

## Base
- Depends on: `v4.19.2`
- Plan: `docs/version-plans/v4.20-to-v5.0-product-roadmap.md` (v4.20.0 section)

## Completion Notes
- `src/safecode/agent/native_tools.py` (new): `NativeToolSpec`, `NativeToolCall`,
  `NativeToolResult` Pydantic models. Wire format: `{"type":"native_tool_call","tool_name":"...","input":{...}}`.
- `src/safecode/agent/native_dispatcher.py` (new): `NativeToolDispatcher` — register,
  dispatch, specs (sorted), system_prompt_section(). Unknown tools return error result.
  Handler exceptions caught and returned as error result (never raise).
- `src/safecode/agent/schemas.py`: added `AgentNativeToolCallResponse` to
  `AgentContractResponse` union and `_REQUIRED_FIELDS_BY_TYPE`. Existing intent/patch
  paths untouched; both protocols coexist.
- **Bug B4 fix** (`context/budget.py`): `TOKEN_CHAR_RATIO` 4 → 3.5; added
  `_CODE_TOKEN_CHAR_RATIO = 3.2`; `estimate_tokens_from_bytes()` accepts optional
  `content_type` hint ("code" → 3.2 ratio); `from_max_chars` uses `math.ceil`.
- **Bug B5 fix** (`context/collector.py`): `_list_files()` now returns `(list[str], bool)`;
  `collect()` adds `"file_tree_meta": {"truncated": true, "cap": N}` when cap fires.
  `FileIndexer.index()` updated to unpack the new tuple.
- **Bug B17 fix** (`context/budget.py`): `ContextBudgetPacker.pack()` skips string/list
  sources once `remaining <= 0` and records a truncation note instead of producing
  empty source entries.
- No stable contract promoted; no safety gate changed.
