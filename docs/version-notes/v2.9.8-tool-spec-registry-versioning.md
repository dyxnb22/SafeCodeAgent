# v2.9.8 - Tool Spec Registry Versioning

## Summary

Adds a stable `version` field to every `ToolSpec` in the local tool registry and introduces
deterministic snapshot coverage for the registry listing shape.

## Changes

- `src/safecode/tools/registry.py`: Added `REGISTRY_SCHEMA_VERSION = "1"` module constant.
  Added `version: str = "1.0.0"` field to `ToolSpec`. All 17 registered tools carry version
  `"1.0.0"` by default.
- `tests/snapshots/registry/tool_registry_v1.json`: New narrow snapshot covering tool name,
  version, permission category, risk, requires_human_approval, and arg schema (name/type/required).
  Prose descriptions intentionally excluded.
- `tests/test_tool_schema_registry.py`: Added `TestToolSpecVersion` (6 tests) and
  `TestRegistrySnapshot` (8 tests) for a total of 14 new tests.

## Invariants

- All `ToolSpec` instances expose a non-empty `version` string.
- `REGISTRY_SCHEMA_VERSION` is a numeric string incremented when the schema field set changes.
- The snapshot is deterministic: byte-identical across repeated runs, keys sorted, no prose.
- Existing tool names, permission categories, and approval semantics are unchanged.
