# v3.3.2 — MCP stdio tools/list Discovery (experimental)

## Summary

Adds experimental one-shot stdio tools/list discovery using `call_stdio`.
No tools/call execution; no runner wiring; existing static MCPDiscovery and
schema behavior unchanged.

## New public symbols (experimental)

### `safecode.mcp.discovery.StdioDiscoveryResult`

Frozen dataclass returned by `discover_stdio_tools`.

Fields:

| Field | Type | Description |
|---|---|---|
| `success` | `bool` | True only when transport and response structure are valid |
| `schemas` | `tuple[MCPToolSchema, ...]` | Parsed schemas; may be empty on success |
| `error` | `str` | Failure reason; empty on success; never contains argv content |
| `skipped_count` | `int` | Number of tool entries skipped due to parse errors |
| `server_name` | `str` | Logical server name passed by the caller |

### `safecode.mcp.discovery.discover_stdio_tools(server_name, argv, *, timeout_seconds, max_output_bytes) -> StdioDiscoveryResult`

Calls the server once with JSON-RPC method `"tools/list"` (no params).

**Fail-closed rules:**

| Condition | Result |
|---|---|
| Transport error (timeout, bad JSON, no output, process failure) | `success=False` |
| Response result not a JSON object | `success=False` |
| Response missing `"tools"` key | `success=False` |
| `"tools"` field not a list | `success=False` |
| Individual entry: not a dict, missing or non-string name, empty name | entry skipped, `skipped_count += 1` |
| Bad description type | tolerated; defaults to `""` |
| Bad `inputSchema` type or missing `properties` | tolerated; `args` defaults to `()` |

All discovered schemas carry `classification="unknown"`.  Call
`classify_with_schema` for richer classification using existing static schemas.

**Security invariants:**

- No params are sent to the server (`tools/list` requires none).
- Error text never contains argv content.
- `timeout_seconds` and `max_output_bytes` are enforced via `call_stdio`.
- `shell=False` always (inherited from `call_stdio`).

### `safecode.mcp.discovery._parse_tool_entry(entry, server_name) -> MCPToolSchema | None`

Private helper. Parses one tool entry from the response. Returns `None` for
malformed entries. Never raises.
