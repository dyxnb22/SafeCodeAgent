# v4.17.2 - Live Connectivity Diagnostics

## Summary

Adds opt-in `--live` flag to `sac doctor` and `sac provider status` for
lightweight HTTP GET connectivity pings to the configured provider base URL.
No authentication sent. Respects `SAFECODE_DOCTOR_UPDATE_CHECK=0`.

## Changes

- `doctor.py`: `_live_provider_ping()` static method attempts a 5-second
  HTTP GET to the provider base URL. Returns PASS/FAIL/SKIP Diagnostic.
  `run_diagnostics()` accepts `live=False` parameter; when True, appends
  a `provider_connectivity` diagnostic after the static checks.
- `cli_ops.py`: `sac doctor` gains `--live` flag.
- `cli_provider.py`: `sac provider status` gains `--live` flag. Shows
  a "Live Connectivity:" section with PASS/FAIL/SKIP verdict when
  enabled. `DiagnosticStatus` import added.

## Tests

- `tests/test_live_connectivity.py`: 7 tests covering offline mode skip,
  empty URL, successful ping, connection failure, doctor integration
  (live=True includes, live=False excludes), and timeout parameter.
