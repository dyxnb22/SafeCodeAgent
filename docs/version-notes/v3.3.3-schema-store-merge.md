# v3.3.3 — Schema Store Merge from Discovery (experimental)

## Summary

Adds a pure helper to merge discovered stdio tool schemas with existing static
schemas.  No stdio execution; no runner behavior changes; existing static
`MCPSchemaStore` behavior unchanged.

## New public symbol (experimental)

### `safecode.mcp.schema.merge_discovered_schemas(static, discovered) -> tuple[MCPToolSchema, ...]`

Pure data transformation — no I/O, no subprocess calls.

**Matching key:** `(server, tool)`.

**Merge rules:**

| Condition | Result |
|---|---|
| Tool in static only | static schema returned as-is |
| Tool in discovered only | discovered schema appended as-is (classification="unknown") |
| Tool in both — classification | **static always wins** (discovered "unknown" never overwrites) |
| Tool in both — description | static kept when non-empty; discovered fills when static is `""` |
| Tool in both — args | static kept when non-empty; discovered fills when static is `()` |
| Tool in both — arg_schemas | always from static; discovered never supplies typed arg schemas |

**Ordering:** Enriched static schemas first (original static order preserved),
then discovered-only schemas appended in their original discovery order.

**Duplicates in discovered:** First occurrence of `(server, tool)` wins;
subsequent duplicates silently ignored.

**Duplicates in static:** Not deduplicated (preserves existing
`MCPSchemaStore` behavior).

**Cross-server:** Different `server` values are never merged, even if `tool`
names match.

## Usage pattern

```python
from safecode.mcp.schema import MCPSchemaStore, merge_discovered_schemas
from safecode.mcp.discovery import discover_stdio_tools

disc_result = discover_stdio_tools("myserver", argv)
if disc_result.success:
    merged = merge_discovered_schemas(
        static_store.schemas,
        disc_result.schemas,
    )
    enriched_store = MCPSchemaStore(schemas=merged)
```
