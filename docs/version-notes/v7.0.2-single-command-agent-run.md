# v7.0.2 — Single-command Agent Run

v7.0.2 improves the non-interactive `sac agent run` happy path.

## Changed

- Added `--auto-edit` and `--full-auto` flags to `sac agent run`, wired through
  the existing `AgentLoop` trust-mode controls.
- Added `--tests` to run one detected project test command after a completed
  agent run.
- Extended JSON output with:
  - `tools_used`
  - `files_changed`
  - `validation`
  - `rollback_command`
- Extended human output with the same compact summary fields.

## Safety

- `--full-auto` still cannot bypass GATE-tier approval.
- `--tests` runs only after the agent reaches `completed`; approval-required
  runs report validation as skipped.
- Test commands execute through the existing `ShellRunner` policy boundary.

## Validation

```bash
uv run pytest tests/test_cli_agent_run.py -q
```
