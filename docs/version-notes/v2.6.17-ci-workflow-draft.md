# v2.6.17 — CI Workflow Draft

## Summary

Adds a GitHub Actions CI draft that runs the full regression suite and the
release checks that do not depend on HEAD being at an exact release tag.

## What changed

- `.github/workflows/ci.yml`: runs Python 3.11, installs the project with dev
  extras, runs `pytest`, `sac release smoke`, `sac release meta`, and a
  changelog preview.
- `tests/test_ci_workflow.py`: verifies the workflow covers the intended checks
  and does not require exact-tag-only gates such as `release check` or
  `release preflight`.

## Verification

```bash
PYTHONPATH=src python3 -m pytest tests/test_ci_workflow.py -q
PYTHONPATH=src python3 -m pytest -q
```
