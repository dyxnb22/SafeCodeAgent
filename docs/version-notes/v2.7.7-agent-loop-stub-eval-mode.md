# v2.7.7 agent-loop-stub-eval-mode

## Goal
Supplement the agent loop test evidence: move beyond the "calculator keyword" mock and provide explicitly scripted, realistic loop-mode eval fixtures.

## Changes
- `src/safecode/eval/loop_runner.py` (new): `ScriptedLLMClient`, `ScriptedStep`, `LLMContractViolation`, `LoopEvalFixture`, `LoopEvalResult`, `LoopModeEvalRunner`, `default_loop_fixtures()`.
- `ScriptedLLMClient`: uses explicit scripted sequences indexed by step position, not keyword matching. Returns `LLMContractViolation` (fail-closed) when the script is exhausted.
- Two realistic default fixtures:
  - `docs-edit`: read → patch, adds safety note to `docs/usage.md`.
  - `python-function-fix`: read → patch, fixes `multiply()` in `src/utils.py`.
- `src/safecode/agent/loop.py`: `AgentLoop.__init__` accepts optional `llm_client` for injection (backward compatible).
- `src/safecode/agent/orchestrator.py`: `AgentOrchestrator.__init__` accepts optional `llm_client` for injection (backward compatible).
- `AgentLoop._execute_patch_proposal_step`: passes `self.llm_client` to `AgentOrchestrator` so the scripted patch response is used end-to-end.
- `src/safecode/cli_ops.py`: `sac eval --mode loop` runs the loop-mode fixtures; `--mode default` (or no flag) preserves existing behavior.
- `tests/test_agent_loop_eval_mode.py`: 13 new tests covering ScriptedLLMClient sequence, violation detection, both fixtures passing, contract failure handling, and CLI integration.

## Tests
- `tests/test_agent_loop_eval_mode.py`: 13 tests, all passing.

## Safety
No real network calls; no real LLM. Loop-mode eval runs in isolated tmp workspaces. Contract violations fail closed and are reported as `LoopEvalResult.violations`.
