# v4.15.0 - sac init Front Door

## Summary

Adds `sac init` as the single recommended first-run entry point. The interactive
TTY wizard covers provider choice, API key source, default model selection, and
policy preset configuration.

## Changes

- `sac init`: New interactive TTY wizard replacing `sac setup --wizard` as the
  recommended first command after installation.
- Non-TTY mode prints a static flag template.
- Validates provider and policy in both TTY and non-TTY mode.
- `sac setup` command is now hidden from root help (still callable).
- `sac setup --wizard` remains hidden but callable for backward compatibility.

## Tests

- `tests/test_cli_init.py`: 8 tests covering help documentation, non-TTY
  template, flag-based invocation, unknown provider/policy refusal, and
  setup hidden-but-callable behavior.
- Help surface tests updated to reflect init replacing setup in the visible
  command list.

All existing tests pass. No stable contract changes.
