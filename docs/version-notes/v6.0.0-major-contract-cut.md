# v6.0.0 — Major Contract Cut

Date: 2026-06-16

v6.0.0 is the second major stable-contract cut after v5.0.0. It promotes two
v5.x surfaces that have release-cycle evidence and clear user-facing
invariants.

## Promoted Stable Contracts

- **Section 18: Trust mode schema** — `suggest`, `auto-edit`, and `full-auto`
  session trust modes are stable. The 10-file guard, checkpoint/audit/rollback
  invariants, command preview delay, and non-persistence of `--full-auto` are
  documented.
- **Section 19: Session rollback** — `sac rollback --session <id>` is stable,
  including reverse checkpoint order, per-file atomic restore behavior, audit
  events, and JSON output shape.

## Deferred

- MCP native tool bridge schema remains experimental.
- Git-aware context remains an internal heuristic.
- `cost.max_tokens_per_session` remains experimental until it has at least one
  release cycle of evidence.
- Live eval harness and golden demo remain project quality/demo assets, not
  public contracts.

## Portfolio Polish

- README now includes a Mermaid architecture diagram, a "Why this is hard"
  section, and a Claude Code/opencode comparison table.
- `docs/demo/resume-and-interview.md` records resume bullets, an interview
  walkthrough, likely questions, and a short demo script.

## Compatibility

- Zero v5.0 breaking changes.
- 19 total stable contracts after promotion.
- PyPI/pipx remains the primary install path; Homebrew is not a required
  release channel.

## Validation

```bash
PYTHONPATH=src python3 -m pytest -q
PYTHONPATH=src python3 -m safecode.cli release preflight
```
