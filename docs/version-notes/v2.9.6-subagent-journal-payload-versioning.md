# v2.9.6 — subagent-journal-payload-versioning (+ v2.9.7 adversarial tests)

## Summary

Adds versioned, tolerant loading for subagent dispatch journal payloads.
Old journals (pre-v2.9.6, without `payload_version`) parse with default
version 1 and remain fully compatible. New journals written by
`record_subagent_dispatch` always include `payload_version: 1`. Unsupported
future versions and malformed payloads emit a `RuntimeWarning` and are
skipped (fail closed), not crashed. Includes adversarial merge tests
(v2.9.7 folded in): duplicate IDs, conflicting observations, near-secret
content, malformed payloads, and blocked-task behavior.

## Changed Files

- `src/safecode/subagents/payload.py` — new: `SubagentDispatchPayload(BaseModel)` with
  `payload_version`, all existing fields, tolerant defaults, `extra="ignore"`
- `src/safecode/subagents/journal_adapter.py` — `_event_to_finding` uses
  `SubagentDispatchPayload.model_validate`; emits `RuntimeWarning` on parse
  failure or unsupported version instead of silently skipping
- `src/safecode/state/journal.py` — `record_subagent_dispatch` always sets
  `payload_version: 1` via `setdefault` (does not override caller-provided version)
- `tests/test_subagent_journal_payload_versioning.py` — 30 new tests including
  adversarial: duplicate IDs, conflicting observations, near-secret content,
  malformed payloads, blocked-task merge behavior, cap enforcement, mixed events
- `pyproject.toml`, `src/safecode/__init__.py` — version bumped to 2.9.6
- `.claude/versions.json`, `.claude/skills/current/SKILL.md` — baseline updated
- `docs/version_implementation_matrix.md` — v2.9.6 row updated

## Constraints Preserved

- Old journals (no `payload_version`) still parse via Pydantic default (backward compat).
- Invalid payloads fail closed with `RuntimeWarning` — no crash, no silent data loss.
- `findings_from_journal_events()` never raises — all exceptions are caught.
- Producer-side secret redaction is preserved (v2.8.7 behavior unchanged).
- No approval, audit, sandbox, or policy gates weakened.
- `SUPPORTED_PAYLOAD_VERSIONS = frozenset({1})` — future versions block cleanly.
