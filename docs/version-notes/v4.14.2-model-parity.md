# v4.14.2 - One-shot --model Flag Parity

## Summary

Adds `--model <alias>` flag to common subcommands so users can set a one-shot
model override directly on the command they're running, instead of only at the
root level.

## Changes

- `sac ask --model <alias>`, `sac edit --model <alias>`, `sac fix --model <alias>`,
  `sac run --model <alias>`, `sac agent run --model <alias>`: all accept a one-shot
  model override.
- Subcommand-level `--model` wins over root-level `sac --model <alias>`.
- Help text for each supported subcommand documents `--model`.
- `sac shell --model` was already supported (v4.14.0).

## Tests

- `tests/test_cli_model_subcommand_parity.py`: 12 tests covering help-text
  documentation across all 6 subcommands, flag acceptance, and env-var
  override order.

No config writes, audit schema changes, or stable contract changes.
