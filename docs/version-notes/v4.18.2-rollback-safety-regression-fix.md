# v4.18.2 — Rollback Safety Regression Fix

Released: 2026-06-06.
Train: v4.17.x-v4.18.x Shell & Interaction UX (completion patch).

## Summary

v4.18.0 introduced `sac rollback --checkpoint <id>` and `--list` (per-patch undo).
The `--checkpoint <id>` path was missing the `ToolCallGate` check that the
`--last` path already had. v4.18.2 corrects this regression.

## Changes

- `src/safecode/cli_core.py` / `src/safecode/checkpoint/`: `--checkpoint <id>` now
  runs `ToolCallGate().check_intent("checkpoint.rollback", approved=True)` before
  touching any file, matching the `--last` path.
- Committed-checkpoint guard (`--force-uncommit` required when checkpoint appears
  committed) extended to the `--checkpoint <id>` path.
- Audit event emission and task sidecar creation wired for the `--checkpoint <id>` path.
- `tests/test_per_patch_undo.py`: 5 new tests covering gate enforcement,
  committed-checkpoint refusal, force-uncommit bypass, audit event emission with
  correct checkpoint ID, and task sidecar creation on the `--checkpoint` path.

## Safety Guarantee

Both `--last` and `--checkpoint <id>` now pass through the same gate sequence:

1. `ToolCallGate().check_intent("checkpoint.rollback", approved=True)`
2. Committed-checkpoint guard (refuses unless `--force-uncommit`)
3. File rollback
4. Audit event with checkpoint ID
5. Task sidecar update

## Test Result

Full suite: 4862 passed, 4 skipped.
