# v3.4.0 — Subagent Pool (T-3.4.0-A)

## Summary

Adds bounded concurrent subagent execution via a new `SubagentPool` in
`src/safecode/subagents/pool.py`. Default max concurrency is 2, configurable via
`SAFECODE_SUBAGENT_MAX`. Results are always returned sorted by `task_id` for
determinism regardless of thread completion order. Worker exceptions are isolated
and do not corrupt other results.

## Key Changes

- **`src/safecode/subagents/pool.py`** (new): `SubagentPool`, `CancellationToken`,
  `_resolve_max_workers()`.
- `SubagentPool.run_all(requests, *, cancellation_token)` runs requests with
  `ThreadPoolExecutor(max_workers=self.max_workers)` and returns results sorted
  by `task_id`.
- `_resolve_max_workers` validates `SAFECODE_SUBAGENT_MAX`; invalid values emit
  `RuntimeWarning` and fall back to default (2) without crashing.
- Existing single-subagent path (via `SubagentDispatchExecutor`) is unchanged.
- **`tests/test_subagent_pool.py`** (new): 22 tests covering default/env/invalid
  env config, cap enforcement, deterministic ordering, and exception isolation.

## Acceptance
