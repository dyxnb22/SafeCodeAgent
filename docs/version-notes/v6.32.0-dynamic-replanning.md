# v6.32.0 — dynamic-replanning

Adds bounded dynamic re-planning for repeated full-auto validation failures.

## Changes

- `AgentSessionState`: persists `replan_count` so resume/retry cannot exceed
  the per-session re-plan cap.
- `AgentLoop`: calls `_try_replan()` after repeated validation/repair failures
  when running in `full_auto`.
- `_PlannerMixin`: builds a failure-aware re-plan prompt with original goal,
  recent journal attempts, failure category, and failure reason.
- Re-planning is conservative: full-auto only, repair attempts >= 2, supported
  failure categories only, and max two re-plans per session.
