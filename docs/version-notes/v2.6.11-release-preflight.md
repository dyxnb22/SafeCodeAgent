# v2.6.11 — Release Preflight

## Summary

Adds `sac release preflight`, a single fast local gate that aggregates release
check, smoke tests, metadata audit, and docs finalization before a release is
considered ready.

## What changed

- `src/safecode/release/preflight.py` (new): `ReleasePreflightResult`,
  `run_release_preflight()`, and `render_release_preflight()`.
- `src/safecode/cli_ops.py`: added `sac release preflight`.
- `src/safecode/release/check.py`: `ReleaseCheckResult.ok` now includes tag
  consistency when tag information is available.
- `docs/install-update.md`: documents the preflight command.
- `tests/test_release_preflight.py`: focused aggregation and CLI tests.

## Behavior

`sac release preflight` exits non-zero if any subcheck fails. The output is a
concise summary by default, with failure details only for checks that need
attention.

## Verification

PYTHONPATH=src python3 -m pytest tests/test_release_preflight.py tests/test_release_checklist_polish.py -q
PYTHONPATH=src python3 -m pytest -q
