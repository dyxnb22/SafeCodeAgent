# v4.7.1 Debug Bundle and Audit Query

Status: implemented.

## Scope

- T-4.7.1-A sac-debug-bundle
- T-4.7.1-B sac-audit-query

## Implementation Notes

- Added `src/safecode/debug/bundle.py` for redacted tar.gz bundle creation.
- Added `sac debug bundle [--task <id>] [--out <path>] [--force] [--json]`.
- Bundle entries include manifest, version metadata, config snapshot, doctor-equivalent data, runtime logs, verified audit events, selected task sidecars, project profile, and memory metadata only.
- Bundles exclude project source code, refuse overwrite without `--force`, and enforce a 5 MiB size cap.
- Added `AuditLogger.iter_events()` as a backward-compatible read helper without changing `AuditEvent`.
- Added `sac audit query [--type <event_type>] [--since <date>] [--task <id>] [--limit N] [--json]`.
- Audit query verifies hash-chain integrity before returning results and never writes audit events.
