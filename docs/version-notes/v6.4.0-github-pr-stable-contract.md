# v6.4.0 — github-pr-stable-contract

## Summary

Promotes the GitHub PR workflow to Stable Contract #20 with structural
safety guarantees that cannot be bypassed by model output or configuration.

## What changed

### `src/safecode/agent/github_write_tools.py`

- `PROTECTED_BRANCHES = frozenset({"main", "master", "trunk"})` — public constant.
- `github_push_branch` now rejects pushes to any protected branch **before**
  any network call. This is a structural code-level gate: the error message
  explicitly states it "cannot be overridden by configuration."
- `_get_current_branch()` — detects the current git branch so implicit pushes
  (no branch arg) are also caught by the protected-branch gate.
- `_build_pr_footer()` — builds a stable SafeCode audit footer appended to
  every PR body: branch name, latest checkpoint ID, timestamp, tool identifier.
- `dry_run=True` parameter added to both tools: validates and previews without
  making any network calls.
- `audit_event_type` changed from `"tool_call_write"` to `"github_pr_created"`
  (create_pr) and `"github_branch_pushed"` (push_branch). Both are stable.

### `docs/public-contracts.md`

Section 20: "GitHub PR Workflow Contract (v6.4.0)" — all stable invariants
documented with source references and non-stable callouts.

### Tests

- `tests/test_github_pr_contract.py` — 35 new contract tests covering:
  protected-branch structural gate (explicit and implicit branch), dry_run
  on both tools, PR footer content, enriched body sent to gh CLI, stable
  audit event types, spec schema validation.
- `tests/test_github_write_tools.py` — two existing tests updated:
  `test_audit_event_type_is_write` → `test_audit_event_types_stable`;
  `test_force_flag_passed_to_git` now uses a feature branch (not main).

## Stable Contract #20 invariants

| Invariant | Enforcement |
|---|---|
| Push to main/master/trunk blocked | Code gate in `_push_branch_handler` |
| PR body includes audit footer | `_build_pr_footer()` always appended |
| `dry_run=True` makes no network calls | Both handlers check flag before subprocess |
| `requires_approval=True` | NativeToolSpec field; cannot be changed by agent |
| `audit_event_type="github_pr_created"` | Stable on GITHUB_CREATE_PR_SPEC |
| `audit_event_type="github_branch_pushed"` | Stable on GITHUB_PUSH_BRANCH_SPEC |
| `shell=False` on all subprocesses | Argv list, no string eval |
| Failure doesn't corrupt local state | Network calls come after all local ops |
