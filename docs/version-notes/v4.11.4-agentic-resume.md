# v4.11.4 - Agentic Resume

## Summary

Extends `sac resume` so passive task recovery also understands agentic sessions
when an existing `AgentJournalStore` journal is present. Resume prints the last
plan, last typed step result, and suggested next safe step. `--continue-agent`
re-enters the existing `AgentLoop.run()` path after passive reconstruction and
keeps approval gates intact.

## Changed Files / Modules

- `src/safecode/cli_resume.py`: adds agentic journal summary and
  `--continue-agent`.
- `src/safecode/agent/loop.py`: adds `AgentLoop.resume_from(session_id)` with
  tolerant journal reconstruction.
- `docs/mvp-user-guide.md`: documents agentic resume behavior.
- `tests/test_resume_agentic.py`: interrupted plan/apply, corrupt/missing
  journal, continue-agent, closed task, and no-auto-run coverage.

## Tests Run

Full suite: `PYTHONPATH=src python3 -m pytest -q`.
