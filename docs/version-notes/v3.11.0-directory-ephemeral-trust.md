# v3.11.0 - directory-ephemeral-trust

## Summary

- T-3.11.0-A per-directory-trust: added user-level `trust.roots` support in `src/safecode/config.py`; roots may apply to subdirectories; project-local `trust` declarations are ignored as untrusted widening attempts; every lookup writes a `trust_config_lookup` audit event.
- T-3.11.0-B ephemeral-trust: added `sac trust grant --until-end-of-session` plus revoke support; grants live only in process memory and are never serialized to config or a grant file; grant/revoke actions are audited.

## Safety Notes

- Trust grants do not bypass approval, audit, redaction, checkpoint, rollback, command policy, or project-root restrictions.
- Project-local config cannot add trust roots or lower user-level policy.
- Ephemeral trust expires when process memory is cleared or the CLI process exits.
