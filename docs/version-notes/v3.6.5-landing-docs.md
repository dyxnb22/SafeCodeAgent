# v3.6.5 — Landing Documentation

## Summary

Adds three user-facing landing documents:
- `docs/why-safecode.md`: explains SafeCode's core value proposition,
  the safety loop, key properties, what SafeCode is not, and experimental surfaces.
- `docs/compare.md`: compares SafeCode to raw LLM usage, autonomous agents,
  git-based approaches, and editor extensions. Includes a v3.6 capability
  summary table with honest stable/preview/experimental labels.
- `docs/troubleshooting.md`: practical fixes for common issues (blocked
  commands, network disabled, approval not found, audit mismatch, version
  drift, LLM failures, rollback issues).

Links all three from README.md. Claims are limited to behaviors documented in
`docs/public-contracts.md` and covered by the test suite. Experimental
surfaces are labeled explicitly throughout.

## Tests

`tests/test_landing_docs.py` — 20 tests enforcing: all three files exist,
required headings are present, experimental labels are used, public-contracts
is linked, README links to all three new docs, and troubleshooting mentions
`sac doctor`, `sac logs`, and `sac rollback`.
