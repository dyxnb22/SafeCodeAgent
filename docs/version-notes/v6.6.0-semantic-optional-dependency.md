# v6.6.0 — semantic-optional-dependency

Semantic retrieval now has an explicit optional install path while keeping the
core package lightweight.

Changes:
- `pyproject.toml`: adds `safecode-agent[semantic]` with
  `sentence-transformers>=2.2.0`.
- `NullEmbeddingBackend`: exposes an install hint and emits one `UserWarning`
  when `create_embedding_backend()` falls back to the null backend.
- `sac index build` and `sac index status`: print a visible semantic-inactive
  hint when the index is backed by the null backend.
- README and MVP guide: document `pip install 'safecode-agent[semantic]'` and
  the `uv pip install` equivalent before `sac index build`.

Validation:
- `PYTHONPATH=src python3 -m pytest tests/test_index_embedding.py -q`
