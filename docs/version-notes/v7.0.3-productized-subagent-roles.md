# v7.0.3 — Productized Subagent Roles

v7.0.3 wraps the existing read-only subagent runner in discoverable built-in
roles.

## Changed

- Added `safecode.subagents.roles` with built-in presets:
  - `explore`
  - `review`
  - `scout`
- Added CLI commands:
  - `sac subagent roles`
  - `sac subagent explore <query>`
  - `sac subagent review [query] [--pending]`
  - `sac subagent scout <query>`
- Role runs remain read-only and use the existing `ReadonlySubagentRunner`.
- Role outputs are journaled as `subagent_dispatch` events so the main agent's
  existing subagent-context merge path can consume them.

## Safety

- Built-in roles do not include write tools.
- No role bypasses existing result-file, audit, or filesystem boundaries.
- Write-capable subagents remain out of scope.
