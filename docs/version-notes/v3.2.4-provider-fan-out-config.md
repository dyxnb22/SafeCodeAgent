# v3.2.4 — Provider Fan-out Config

## Summary

Adds primary/fallback provider routing so hard transport failures from the
primary LLM provider can fall back to a secondary provider. Both primary and
fallback must pass network policy checks. Policy blocks, validation failures,
and `RecoverableContractFailure` are not routed to the fallback.
Default behavior is unchanged when no fallback is configured.

## What Changed

- `src/safecode/config.py` — `LLMConfig` gains three new optional fields:
  - `fallback_provider: str | None = None`
  - `fallback_model: str | None = None`
  - `fallback_base_url: str | None = None`
- `src/safecode/llm/factory.py` — rewritten to add:
  - `_create_single_client(config, *, session_id)`: creates one concrete client.
  - `FanOutLLMClient(primary, fallback=None)`: proxies all four `LLMClient` methods.
    On `RuntimeError` from primary, emits a redacted `RuntimeWarning` and delegates
    to fallback. Does NOT catch `PermissionError` (network policy) or `ValueError`
    (hard contract). `RecoverableContractFailure` (returned value) passes through.
  - `_log_fanout(method, exc)`: emits the warning with method name and exception
    type only — no prompt text, no context content.
  - `create_llm_client` builds a `FanOutLLMClient` when `fallback_provider` is set;
    the fallback config has its own fallback fields cleared to prevent nesting.
  - Streaming is proxied to the primary (`stream_chat`) without fan-out.
- `tests/test_llm_provider_fanout.py` (new): 24 tests covering no-fallback path,
  primary success, hard failure routing, safety gate enforcement, log redaction,
  factory behavior, and streaming proxy.

## Safety / Contract Status

- Default provider: `mock` — unchanged.
- Network policy: enforced on both primary and fallback clients at init.
- `PermissionError` from policy blocks propagates without fan-out routing.
- `ValueError` from hard contract violations propagates without fan-out routing.
- `RecoverableContractFailure` is a returned value — not caught by fanout.
- Provider behavior remains experimental; not promoted to stable contract yet.
- Public contract snapshots: unchanged, all pass.
- No real network calls in tests.
