# v2.7.5 quickstart-command

## Goal
Reduce first-time user friction by providing a single guided entry point.

## Changes
- New `sac quickstart` command (`src/safecode/cli_quickstart.py`).
- On a fresh repo: offers to create `.sac/config.toml` with safe defaults (mock provider, balanced policy).
- On an existing repo: reads and displays current provider/policy; does not overwrite config unless `--force`.
- Recommends the `cli-version-flag` demo workflow and prints its task + commands.
- `--demo` flag materialises the recommended demo project into `examples/demo-workflows/` (or `--demo-dest`).
- Prints concrete next-step commands (`sac ask`, `sac edit`, `sac apply`, `sac rollback`); never claims those commands already ran.
- `--yes` skips confirmation prompts (CI-safe).
- README Core Commands section updated to include `quickstart`.
- `docs/mvp-user-guide.md` updated with quickstart path.

## Tests
- `tests/test_quickstart.py`: 8 focused tests covering fresh repo, no-overwrite, --force, output honesty, --demo materialize, idempotency.

## Safety
No new file-write paths bypass checkpoint/audit. Config creation delegates to the existing `write_setup` helper.
