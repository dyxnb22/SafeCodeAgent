# v3.6.0 — Release Publish + CI Matrix

## Summary

- **T-3.6.0-A `release-publish`**: Adds `sac release publish --dry-run/--sign` command.
  Dry-run is the safe default and is deterministic (no subprocess, no file writes).
  Real publish requires a clean matching git tag at HEAD and `SAFECODE_PUBLISH=1`.
  Signing is optional (`--sign`) and fails closed when neither `cosign` nor `gpg` is found.
  No publish happens during tests.
- **T-3.6.0-B `ci-matrix`**: Expands GitHub Actions to Python 3.11/3.12/3.13 × {ubuntu-latest, macos-latest} with `fail-fast: false`.
  Adds an advisory Windows smoke lane (`smoke-windows`, `continue-on-error: true`).
  Loop eval and live-provider lanes remain advisory and gated (unchanged).

## New files

- `src/safecode/release/publish.py` — `PublishResult`, `run_release_publish`, `render_publish_result`
- `tests/test_release_publish_dry_run.py` — 38 tests covering dry-run safety, real publish gating, sign fails-closed, CLI surface
- `tests/test_ci_matrix.py` — 28 tests guarding CI YAML shape (matrix versions, OS, Windows smoke, advisory lanes)

## Modified files

- `src/safecode/cli_ops.py` — `sac release publish` command (visible in `release --help`)
- `.github/workflows/ci.yml` — matrix strategy for `test` job; new `smoke-windows` advisory job

## Invariants

- `run_release_publish(dry_run=True)` never calls `subprocess.run`, never writes files.
- `run_release_publish(dry_run=False)` fails immediately without `SAFECODE_PUBLISH=1`.
- Tag mismatch or absent tag always blocks real publish before any build step.
- Sign fails closed: missing tooling returns an error, never continues.
- CI matrix has `fail-fast: false` so one OS failure does not cancel others.
- Windows smoke lane is `continue-on-error: true` (advisory).
