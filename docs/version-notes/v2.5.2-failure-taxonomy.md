# v2.5.2 — Failure Taxonomy

## Summary

Adds a structured failure taxonomy for task eval replay results, without breaking the v2.5.1 runner API.

## New file

`src/safecode/eval/failures.py` — taxonomy enum, typed failure dataclass, and classifier.

## API

### `FailureCategory` (StrEnum)

Eleven stable categories:

| Value | Meaning |
|---|---|
| `context_miss` | Agent lacked needed context to produce a correct result |
| `patch_parse` | Patch could not be parsed from the LLM output |
| `validation` | Validation command exit code, output, diff, or file-changed constraint failed |
| `command_blocked` | A forbidden command pattern was observed |
| `forbidden_file_write` | A forbidden file write was detected (safety gate) |
| `forbidden_file_changed` | A forbidden-changed-files constraint was violated |
| `setup` | Workspace materialisation or setup command failed |
| `timeout` | A validation command timed out |
| `model_error` | The LLM produced an error or refused to respond |
| `audit_unverified` | Expected audit events could not be verified |
| `unknown` | Failure did not match any known pattern |

### `ClassifiedFailure` (frozen dataclass)

```python
@dataclass(frozen=True)
class ClassifiedFailure:
    category: FailureCategory
    reason: str       # human-readable summary
    detail: str | None = None   # matched pattern/file from structured signal

    def as_dict(self) -> dict[str, object]: ...
```

### `classify_replay_result(result) -> list[ClassifiedFailure]`

Deterministic classifier. Returns `[]` for passing results. Structured signals (dedicated `ReplayResult` fields) are consumed first; remaining `failure_reasons` are categorised by known keyword prefixes.

## Integration

`ReplayResult` gains `classified_failures: list[ClassifiedFailure] = field(default_factory=list)` — existing callers are unaffected. `TaskReplayRunner` populates this field in both the normal and error-result paths.
