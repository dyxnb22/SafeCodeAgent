# v4.15.1 - Session-scoped Model Switching

## Summary

Makes `sac model <alias>` session-only by default. Model selection now sets
process-level env vars instead of writing to disk. Persistence requires the
explicit `--save` flag.

## Changes

- `sac model <alias>`: session-only by default; sets `SAFECODE_LLM_PROVIDER`
  and `SAFECODE_LLM_MODEL` env vars.
- `sac model --save <alias>`: persists to user config (previous default behavior).
- `sac model status`: new subcommand showing session override vs persisted model.
- `sac model` (no args): now shows session + persisted status.
- `SAFECODE_LEGACY_MODEL_PERSIST=1`: deprecated env var restores old persist-by-default.
- `sac doctor`: warns when `SAFECODE_LEGACY_MODEL_PERSIST=1` is set.

## Tests

- `tests/test_cli_model_session_scope.py`: 6 tests covering session-only default,
  --save persistence, status command, no-args status, and legacy env var warning.

All existing tests pass. No stable contract changes.
