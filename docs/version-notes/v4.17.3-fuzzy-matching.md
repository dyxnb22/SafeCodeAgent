# v4.17.3 - Levenshtein Fuzzy Matching

## Summary

Replaces hardcoded typo-suggestion table with dynamic Levenshtein distance
fuzzy matching for model IDs and provider names. Applied to `sac model`,
`sac provider add`, `--model` flag, and shell `/model`.

## Changes

- `llm/provider_profiles.py`: `_levenshtein_distance()`, `_fuzzy_match()`,
  `_fuzzy_match_model()`, `_fuzzy_match_provider()` — pure functions for
  edit-distance matching within max distance 2. `_collect_known_model_ids()`
  gathers candidate IDs from preset aliases and active profile.
  `ProviderProfile.resolve_model()` uses `_fuzzy_match_model()` instead of
  the removed `_MODEL_TYPO_SUGGESTIONS` dict. Suggestions display the matched
  model ID: `"Did you mean 'deepseek-v4-flash'? (from 'flassh')"`.
- `cli_provider.py`: `provider_add` uses `_fuzzy_match_provider()` to suggest
  the closest provider name when user types an unknown name.

## Tests

- `tests/test_fuzzy_matching.py`: 13 tests covering edit distance (identical,
  empty, substitution, insertion/deletion), exact match, typo correction,
  beyond-threshold rejection, provider name matching, model matching against
  profile, known ID collection, and `resolve_model` integration.
