# v6.35.0 — search-symbol-discovery

Improves `search_symbol` discoverability and definition recall.

## Changes

- `search_symbol` now falls back to the Python walker when ripgrep returns no
  matches, not only when ripgrep is unavailable.
- The walker matches snake_case and camelCase/PascalCase variants, improving
  cross-language symbol localization.
- The native tool spec now explicitly tells models to use `search_symbol`
  before broad file reads for named functions, classes, types, constants, and
  traceback symbols.
- `ContextCollector` injects concise `tool_guidance` with candidate names from
  the current goal.
