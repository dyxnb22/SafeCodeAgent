## Completion Notes
- `src/safecode/agent/read_tools.py` (new): four read-only native tools.

  | Tool | Behaviour |
  |---|---|
  | `read_file` | Read up to 400 lines; redacts secrets; refuses root escapes, sensitive, and binary files. |
  | `list_files` | List files/dirs under a project path; respects SKIP_DIRS; `recursive` option; cap 500. |
  | `search_files` | Literal substring search; returns `{file, line, content}` list capped at 100; `include_glob` filter; skips sensitive/binary; redacts. |
  | `grep_files` | Regex search using `re` module; `case_insensitive` option; same cap and safety gates. |

- All four tools: `requires_approval=False`, `audit_event_type="tool_call_read"`.
- `register_read_tools(dispatcher, project_root)` helper injects project_root into all handlers.
- Safety invariants: path validated against project root; sensitive-path/binary checks via existing
  `SKIP_DIRS`, `SENSITIVE_NAMES`, `SENSITIVE_PATTERNS` constants from `context/collector.py`;
  `redact_secrets()` on all text output.
- No stable contract promoted; no safety gate changed.
