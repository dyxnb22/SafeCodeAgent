# v2.6.9 — Release Docs Finalization Guard

## Summary

Adds a final release docs guard that checks the human-facing documentation was updated before cutting a release: version-note file exists, SKILL.md baseline mentions the current version, and README or install-update doc mentions at least one release command.

## Changes

- `src/safecode/release/docs_guard.py` (new): `DocsGuardResult` dataclass; `check_docs_finalized()` accepts injected paths and `release_commands_documented` for testability; `_docs_mention_release_commands()` scans README and docs/install-update.
- `src/safecode/release/smoke.py`: added `_check_docs_finalized()` smoke case wired into `run_smoke_tests()`.
- `docs/install-update.md`: added "Release Checks" section documenting `sac release check`, `sac release smoke`, and `sac release meta`.
- `.claude/skills/current/SKILL.md`: updated baseline to v2.6.9.

## Test coverage

`tests/test_release_docs_guard.py` (new):
- All three checks pass → ok
- Missing version-note → issue reported
- Stale SKILL.md → issue reported
- Missing release-command docs → issue reported
- README with command → docs check passes
- install-update.md with command → docs check passes
- No docs at all → commands check fails
- `RELEASE_COMMANDS` constant is non-empty

`tests/test_release_smoke.py`: added `docs_finalized` to `test_all_cases_present`.
