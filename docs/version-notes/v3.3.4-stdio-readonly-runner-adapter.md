# v3.3.4 — Experimental Read-Only Stdio Runner Adapter

## Summary

Adds `StdioReadOnlyAdapter` — an experimental read-only adapter that calls
`tools/call` via `call_stdio` for tools classified read-only by the existing
classification gate.  Disabled by default; not wired into `MCPReadOnlyRunner`.
Callers must instantiate explicitly.

## New public symbols (experimental)

### `safecode.mcp.stdio_runner.StdioReadOnlyAdapter`

Self-contained read-only adapter for stdio MCP servers.

```python
adapter = StdioReadOnlyAdapter(
    server_name="myserver",
    argv=["python", "-m", "my_mcp_server"],
    schemas=[...],                 # optional MCPToolSchema list
    timeout_seconds=10.0,          # passed to call_stdio
    max_output_bytes=256 * 1024,   # passed to call_stdio
)
result = adapter.call_readonly("get_files", {"path": "/src"})
```

**Classification gate (same as existing runner):**

| Classification | Action |
|---|---|
| `"read"` | Calls `call_stdio("tools/call", params={"name": tool, "arguments": args})` |
| `"write"` | Blocked immediately; `blocked=True, exit_code=126` |
| `"unknown"` | Blocked immediately; `blocked=True, exit_code=126` |

**Security invariants:**
- `shell=False` always (inherited from `call_stdio`).
- Timeout kills the process; exit code 124 on timeout.
- Max output size enforced; fails closed if exceeded.
- `call_args` values never copied into error text.
- All failures return `StdioCallResult` — never raises.
- `RuntimeWarning` emitted on block or transport failure (consistent with existing MCP runner logging style).

**Opt-in requirement:** Not imported or used by `MCPReadOnlyRunner` or `MCPReadToolExecutor`.

### `safecode.mcp.stdio_runner.StdioCallResult`

Frozen dataclass returned by `StdioReadOnlyAdapter.call_readonly`.

| Field | Type | Description |
|---|---|---|
| `server` | `str` | Logical server name |
| `tool` | `str` | Tool name called or attempted |
| `classification` | `str` | Classification used at the gate |
| `output` | `str` | Extracted text output; empty on failure |
| `error` | `str` | Failure or block reason; empty on success; never contains call_args |
| `exit_code` | `int` | Process exit code or synthetic (124=timeout, 126=blocked/size, 127=not-found) |
| `success` | `bool` | True only when transport succeeded |
| `blocked` | `bool` | True when blocked by classification gate; False when transport was attempted |

### `safecode.mcp.stdio_runner._extract_output(result)`

Private helper. Extracts text from MCP content-block format
(`{"content": [{"type": "text", "text": "..."}]}`). Falls back to JSON
serialisation. Never raises.
