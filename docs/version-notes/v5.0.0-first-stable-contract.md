# v5.0.0: first-stable-contract

## Base
- Depends on: `v4.25.2`
- Plan: `docs/version-plans/v4.20-to-v5.0-product-roadmap.md` (v5.0.0 section)

## Theme
First major version boundary since v4.0.0. Native tool-use shell graduates
from EXPERIMENTAL to stable contract. Zero breaking changes to the twelve
v4.0.0 stable contracts.

## Completion Notes

- `src/safecode/agent/read_tools.py`: `READ_FILE_SPEC`, `LIST_FILES_SPEC`, `SEARCH_FILES_SPEC`, `GREP_FILES_SPEC` — `experimental=False` (stable since v5.0.0).
- `src/safecode/agent/write_tools.py`: `EDIT_FILE_SPEC`, `WRITE_FILE_SPEC` — `experimental=False`.
- `src/safecode/agent/command_tool.py`: `RUN_COMMAND_SPEC` — `experimental=False`.
- `src/safecode/cli_ops.py`: `_V5_STABLE_CONTRACTS` constant (12 entries); `sac version --json` data gains `stable_contracts` list.

### Contract documentation

- `docs/versioning-policy.md`: "v5.x Contract Promise" section; v5.0.0 changelog entry.
- `docs/security/threat-model-v3.6.md`: v5.0 stable contract promotion note — five mandatory security properties now part of stable contract.
