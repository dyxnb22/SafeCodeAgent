# v7.1.0 — Eval Suite Split

v7.1.0 starts the eval maturity train by separating live eval tasks into
product-useful suites.

## Changed

- Added live eval suite taxonomy:
  - `regression`
  - `capability`
  - `safety`
  - `cost-perf`
- Added `classify_eval_suite()` and `filter_live_fixtures()` helpers.
- Added `sac eval --mode live --eval-suite <suite>`.
- Documented suite intent in `docs/demo/eval-methodology.md`.

## Why

Regression evals should protect behavior that already works. Capability evals
should be hard enough to show improvement. Mixing them makes a 100% score look
better than it is.
