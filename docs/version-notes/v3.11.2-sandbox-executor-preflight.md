# v3.11.2 - sandbox-executor-preflight

## Summary

- T-3.11.2-A sandbox-executor-preflight: added `src/safecode/sandbox/executor_preflight.py` and `sac sandbox executor-preflight <backend>`.
- Backends accepted: `noop`, `docker`, `seatbelt`, `bubblewrap` plus internal aliases.
- Real Docker, macOS Seatbelt, and Linux Bubblewrap execution now requires both a passing local preflight record and explicit env opt-in.
- T-3.11.2-B sandbox-promotion-docs: documented promotion state in install/update docs and the threat model; `sac doctor` reports promotion state per backend.

## Promotion State

- Noop: policy-gated default; no OS containment.
- Docker: preview unless current host passes executor preflight and `SAFECODE_SANDBOX_DOCKER=1` is set.
- macOS Seatbelt: preview unless current host passes executor preflight and `SAFECODE_SANDBOX_SEATBELT=1` is set.
- Linux Bubblewrap: preview unless current host passes executor preflight and `SAFECODE_SANDBOX_BUBBLEWRAP=1` is set.
