# v3.7.0 — sac fix + stack-aware quickstart

## Summary

- **T-3.7.0-A `sac fix` command** (`src/safecode/cli_fix.py`): new command that detects the
  project's test command, runs it, redacts the failure output, and invokes the existing
  `AgentOrchestrator.edit()` path to propose a repair patch. The pending patch is left for
  `sac apply` — no approval gate is bypassed. Supports `--test-command` override and `--json`
  output via `CLIJSONResponse`. 22 new tests in `tests/test_sac_fix.py`.

- **T-3.7.0-B stack-aware quickstart** (`src/safecode/cli_quickstart.py`): `sac quickstart`
  now detects `pyproject.toml` (Python), `package.json` (TypeScript/Node), `go.mod` (Go),
  and `Cargo.toml` (Rust). Next-step commands and demo hints are adapted per stack. Unknown
  stack preserves the existing generic behavior. 11 new tests added to `tests/test_quickstart.py`.

## Safety invariants preserved

- `sac fix` does not bypass redaction, approval, checkpoint, or audit gates.
- The fix patch is proposed via `AgentOrchestrator.edit()` and left pending for user review.
- Shell commands are not run through `ShellRunner` (test runner is a bounded subprocess with
  `shell=False` and a 120-second timeout; it is read-only with respect to project files).
