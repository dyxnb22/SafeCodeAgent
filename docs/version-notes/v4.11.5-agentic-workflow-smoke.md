# v4.11.5 - Agentic Workflow Smoke

## Summary

Adds experimental `sac smoke agentic [--json]`, a deterministic mock-only smoke
suite for the Agentic-Lite loop. The suite covers plan-only, rejected edit,
apply plus validation pass, validation failure with repair, validation
`loop_no_progress`, and interrupted apply plus resume recovery.

## Changed Files / Modules

- `src/safecode/cli_smoke.py`: `agentic` smoke command, six scripted scenarios,
  JSON step-kind/final-status reporting, and compact text output.
- `docs/troubleshooting.md`: "Agent loop smoke failures" section.
- `docs/version_implementation_matrix.md`: v4.11.5 row.
- `.claude/versions.json`: marks v4.11.x complete and current version
  v4.11.5.
- `tests/test_smoke_agentic.py`: scenario coverage, JSON envelope, mock-only
  guard, final statuses, and experimental command behavior.

## Tests Run

Focused: `PYTHONPATH=src python3 -m pytest -q tests/test_smoke_agentic.py tests/test_validation_loop.py tests/test_resume_agentic.py`.

Docs/metadata: `PYTHONPATH=src python3 -m pytest -q tests/test_versions_json_sync.py tests/test_docs_claims_guard.py`.

Full suite: `PYTHONPATH=src python3 -m pytest -q`.

## Safety / Contract Note

No new stable contracts promoted. `sac smoke agentic` remains EXPERIMENTAL,
mock-only, bounded, network-free, and never applies patches to the SafeCode
repository, commits upstream, pushes, or calls real providers.
