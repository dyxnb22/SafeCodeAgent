# v5.8.2 — v6.0 Preparation Baseline

## Summary

v5.8.0–v5.8.2 close the v5.6–v5.8 roadmap and establish the pre-v6.0
baseline.

**v5.8.0 — cost-guardrails:**
- `CostConfig` model (`max_tokens_per_session`, `fallback_on_usd`).
- Budget checking: 90% warning, 100% stop, +10% extension if user continues.
- `/budget` shell command.
- Config merge: project config can only lower the token cap, not raise it.

**v5.8.1 — v6-contract-preparation:**
- `docs/v6-contract-candidates.md`: 8 candidate surfaces assessed.
- Trust mode schema and `sac rollback --session` approved for v6.0 promotion.
- Cost cap conditional; MCP bridge/git context/live eval/golden demo deferred.
- Budget: ≤5 new contracts, zero v5.0 breaking changes.

**v5.8.2 — v6-prep-docs:**
- README roadmap table.
- v6.0 churn budget in versioning policy.
- v6.0 candidate surfaces in public-contracts.md.
- project-final-status-and-roadmap.md to v5.8.2 pre-v6 baseline.
- Version/tag consistency: pyproject.toml and `__version__` bumped to 5.8.2.
- Homebrew removed as a production install channel; PyPI/pipx is the only
  required path.
- Golden demo script fixed to actually run end-to-end.
