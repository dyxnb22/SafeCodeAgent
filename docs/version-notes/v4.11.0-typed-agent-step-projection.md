# v4.11.0 - Typed Agent Step Projection

## Summary

Adds the experimental typed step projection on the existing `AgentLoop`.
`TypedAgentStep` and `TypedAgentStepResult` classify legacy loop behavior by
step kind and status while preserving the existing `AgentStepResult` /
`AgentRunResult` return contracts. Mutating kinds remain approval-required.

## Changed Files / Modules

- `src/safecode/agent/step_model.py`: typed step/result models, kind/status
  literals, approval requirement derivation, serialization helpers.
- `src/safecode/agent/loop.py`: projects existing step outcomes into typed
  steps/results and exposes `last_typed_step` / `last_typed_result`.
- `src/safecode/agent/__init__.py`: exports the typed step model surface.
- `tests/test_agent_loop_typed_steps.py`: classification, approval-required
  kinds, stale approval, dirty tree, invalid model output, and compatibility
  coverage.

## Tests Run

Focused local evidence: `PYTHONPATH=src python3 -m pytest -q tests/test_agent_loop_typed_steps.py tests/test_agent_loop_patch.py tests/test_agent_loop_error_recovery.py tests/test_agent_loop_typed_actions.py`.

Full-suite local evidence: `PYTHONPATH=src python3 -m pytest -q`.

## Safety / Contract Note

No new stable contracts promoted. The typed projection is EXPERIMENTAL and
wraps existing `AgentLoop` behavior; no `AgentTaskRunner` or parallel task
runner was introduced.
