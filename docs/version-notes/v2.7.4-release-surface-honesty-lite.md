# v2.7.4 release-surface-honesty-lite

Lightweight release surface cleanup: internal/advanced commands are labelled in help text,
docs main flow is clarified, no commands removed.

## Changes

- **CLI help labels**: `sac release signoff` now shows `[internal]` and "not required" in help.
  `sac release check`, `smoke`, `meta`, and `checklist` now show `[advanced]` and
  `Prefer: sac release preflight` or similar guidance.
- **docs/install-update.md updated**: `## Release Checks` renamed to `## Release Flow`.
  Main recommended path is `bump -> pytest -> tag -> preflight -> changelog as needed`.
  Advanced/internal commands (`check`, `smoke`, `meta`, `checklist`, `signoff`) are listed
  separately under their labels. Signoff does not appear in the main code block.
- **New test file `tests/test_release_surface_honesty.py`** (18 tests): Verifies labelling,
  callability, and docs flow.
- All commands remain callable; no breaking changes.

## Acceptance

- `PYTHONPATH=src python3 -m pytest tests/test_release_surface_honesty.py -v` → 18 tests pass.
- `PYTHONPATH=src python3 -m pytest -q` → full suite passes.
- `sac release signoff --help` output contains "internal" or "not required".
- `sac release bump --help` does not contain "deprecated" or "internal".
