# v7.1.4 Real-Task Benchmark

## Status

Implemented on `dev/v4.19` and tagged as `v7.1.4`.

## What Changed

- Added `safecode.eval.real_task` as the real-task benchmark lane.
- Added `sac eval --mode real-task`.
- Selected built-in SWE-bench-Lite-compatible tasks whose `instance_id` does
  not start with `safecode__`, separating external-project tasks from local
  synthetic micro-fixtures.
- Added provenance manifests for the selected benchmark slice.
- Saved real-task reports under `.sac/eval/real-task/latest.json`.

## Acceptance

- `uv run pytest tests/test_eval_real_task_benchmark.py tests/test_eval_swebench_adapter.py::TestBuiltinFixtures -q`
- `uv run sac eval --help`
- `uv run pytest tests/test_release_metadata.py tests/test_versions_json_sync.py -q`

## Notes

The first built-in real-task case is `arrow__parser-error-boundary`, derived
from an external project parser exception boundary issue. The lane intentionally
reuses the SWE-bench adapter so provenance, validation commands, and replay
behavior stay consistent.
