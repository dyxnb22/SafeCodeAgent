# v6.3.0 — chunking-and-local-embedding-index

## Summary

Adds a local embedding index with pluggable backend and SQLite storage.

## What changed

### New modules

- `src/safecode/index/chunker.py` — `TextChunk` dataclass and `chunk_file()` /
  `chunk_files()` helpers; splits files into ~50-line / 2000-char chunks;
  skips binaries and short content.
- `src/safecode/index/embedding_backend.py` — `EmbeddingBackend` ABC,
  `NullEmbeddingBackend` (zero vectors; keyword-only fallback),
  `SentenceTransformerBackend` (real embeddings if library installed),
  `create_embedding_backend()` factory, `cosine_similarity()` pure-Python.
- `src/safecode/index/embedding_store.py` — `EmbeddingStore`: SQLite WAL store
  at `.sac/index/embeddings.db`; incremental build (skip unchanged hashes);
  `search()` returns `SemanticSearchResult` list; `status()` returns `IndexStatus`.

### CLI additions (`src/safecode/cli_project.py`)

- `sac index build [--force] [--json]` — build or update embedding index.
- `sac index status [--json]` — show index stats (files, chunks, built-at, backend).

### Tests

- `tests/test_index_embedding.py` — 42 tests covering chunker, null backend,
  cosine similarity, EmbeddingStore build/search/status/skip/force, and CLI smoke.

## Invariants

- All tests pass without `sentence-transformers` installed (null backend fallback).
- Build is incremental: unchanged chunks (same `content_hash`) are skipped.
- `search()` always returns `[]` when null backend is active (no false semantic scores).
