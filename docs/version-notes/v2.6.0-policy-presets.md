# v2.6.0 — Policy Presets

## Summary

Adds explicit, named safety presets (`strict`, `balanced`, `experimental`) to `src/safecode/config.py`.  Legacy names `normal` and `learning` remain fully functional as aliases.  No new runtime dependencies.

## New public API

| Symbol | Location | Purpose |
|---|---|---|
| `POLICY_PRESETS` | `config.py` | Maps canonical preset name → dict of safety-knob values |
| `normalize_policy_name(name)` | `config.py` | Resolves aliases: `"normal"` → `"balanced"`, `"learning"` → `"experimental"` |
| `apply_policy_preset(config)` | `config.py` | Unconditionally sets `shell.*`, `sandbox.*`, `hooks.*` knobs to the preset defined by `config.policy` |
| `POLICY_ORDER` | `config.py` | Extended with `"balanced"` (1) and `"experimental"` (0); aliases share the same level as their canonical counterpart |

## Preset knob values

| Knob | strict | balanced | experimental |
|---|---|---|---|
| `shell.allow_readonly_without_confirm` | `False` | `True` | `True` |
| `shell.require_confirm_for_medium` | `True` | `True` | `False` |
| `shell.block_high_risk` | `True` | `True` | `True` |
| `shell.allowed_commands` | `[git, ls, pwd]` | `[echo, git, ls, pwd]` | `[cat, echo, find, git, grep, ls, pwd]` |
| `sandbox.restrict_to_project_root` | `True` | `True` | `True` |
| `sandbox.network_enabled` | `False` | `False` | `False` |
| `sandbox.network_allowlist` | `[]` | `[]` | `[]` |
| `hooks.allow_medium_after_apply` | `False` | `False` | `True` |

`strict ⊂ balanced ⊂ experimental` for allowed_commands (set inclusion).

## Backward compatibility

- `"normal"` continues to work; `normalize_policy_name("normal") == "balanced"` and `POLICY_ORDER["normal"] == 1`.
- `"learning"` continues to work; `normalize_policy_name("learning") == "experimental"` and `POLICY_ORDER["learning"] == 0`.
- `merge_trusted_config()` and `_stricter_policy()` are unchanged in logic; they work correctly with all five names because `POLICY_ORDER` covers all of them.
- `SafeCodeConfig.load()` is unchanged; `apply_policy_preset()` is a standalone utility (not auto-applied in `load()`).

## Invariants preserved

- Project config cannot lower user-level policy or safety knobs (existing `merge_trusted_config` logic).
- `SAFECODE_POLICY` env var can only raise effective policy, never lower it.
- `block_high_risk` and `restrict_to_project_root` are `True` in every preset.
- `network_enabled` defaults to `False` in every preset.
