# v3.2.2 — Structured Output Validation

## Summary

Hardens model-output parsing so malformed provider JSON becomes a recoverable
contract-shaped failure, not a crash or unsafe fallback. Existing mock/scripted
LLM tests are unchanged. Public contract snapshots continue to pass.

## What Changed

- `src/safecode/agent/schemas.py`: added `validate_provider_json(raw, *, step, method)`
  which returns `AgentContractResponse | RecoverableContractFailure`. Handles:
  - invalid/non-JSON → `RecoverableContractFailure`
  - non-object JSON → `RecoverableContractFailure`
  - missing or empty `type` field → `RecoverableContractFailure`
  - missing required fields per type → `RecoverableContractFailure`
  - Pydantic validation errors (wrong types) → `RecoverableContractFailure`
  - structurally valid mismatched type (e.g. plan where tool_intent expected) → `ValueError` (hard, fail-closed)
  - `_REQUIRED_FIELDS_BY_TYPE` dict maps each contract type to its required field set.
- `src/safecode/llm/openai_client.py`: `_chat_agent_json` now calls `validate_provider_json`
  instead of `parse_agent_contract_response`. `choose_tool` returns `RecoverableContractFailure`
  (not raises) so the agent loop can retry exactly once. `plan` raises `ValueError` for
  recoverable failures (plan failures are not retryable in the current loop).
- `tests/test_llm_structured_output.py` (new): 38 tests covering invalid JSON, missing
  required fields, wrong field types, extra fields tolerated, recoverable failure shape,
  existing behavior unchanged, no crash on malformed body.

## Design

- `parse_agent_contract_response` is unchanged — existing callers are not affected.
- `validate_provider_json` is the new hardened entry point for provider-sourced output.
- Soft failures (parse errors, missing fields, type mismatches) → `RecoverableContractFailure`.
- Hard failures (valid parse but wrong contract type) → `ValueError` (fail-closed).
- Extra/unknown fields are tolerated by Pydantic's default behaviour.

## Safety / Contract Status

- Public contract snapshots: unchanged, all pass.
- Agent contract schemas are not weakened — no silent coercion of unsafe/missing fields.
- Retry policy blocks, validation failures, and user-stop states are not retried.
- Default provider remains `mock`. No real network calls in tests.
