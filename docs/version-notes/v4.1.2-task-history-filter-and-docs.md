## What Changed

### T-4.1.2-A: History Task Filter (EXPERIMENTAL)

`sac history` now accepts `--task <id>` to filter the audit table to events
whose `metadata["task_id"]` exactly matches the given id.

**`AuditLogger.read_by_task_id(task_id, limit=200)`** (new method):
- Returns events with `metadata["task_id"] == task_id` (exact match).
- Empty `task_id` → returns `[]`.
- Missing log file → returns `[]`.
- Corrupted JSONL lines are silently skipped.
- Returns raw events; caller is responsible for redaction.
- `AuditEvent` field set is unchanged (task_id remains inside `metadata` only).

**`sac history --task <id>`** (new option):
- EXPERIMENTAL flag in the `--help` text.
- Filters the in-memory event list before rendering the Rich table.
- "No audit events found" printed when the filtered list is empty.
- Existing `sac history` (no `--task`) is unchanged.
