# v4.10.2 — Provider Doctor Diagnostics

## Summary

Adds a provider-diagnostics section to `sac doctor`. For the configured
provider, doctor checks: API key environment variable present (non-empty),
`base_url` parseable without network I/O, configured model name non-empty,
and network policy permits the base URL.
Doctor makes **no** provider network request in this batch; the existing
PyPI update check is gated behind an offline-safe knob introduced here.
All diagnostics report PASS / SKIP / FAIL with actionable hints.

## Changed Files / Modules

- `src/safecode/doctor.py`: `_provider_diagnostics()` method; update-check
  gate for the PyPI check (`SAFECODE_DOCTOR_UPDATE_CHECK=0` env var).
- `tests/test_provider_doctor.py`: key-present, key-missing, base-url-blank,
  network-policy-block, and update-check gate tests.

## Tests Run

Targeted: `tests/test_provider_doctor.py` (all pass).
Full suite clean.

## Safety / Contract Note

No new stable contracts promoted. All new surfaces are EXPERIMENTAL.
