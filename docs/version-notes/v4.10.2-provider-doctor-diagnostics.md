# v4.10.2 — Provider Doctor Diagnostics

## Summary

Adds a provider-diagnostics section to `sac doctor`. For the configured
provider, doctor checks: API key environment variable present (non-empty),
`base_url` reachable via offline-safe DNS check (no live HTTP request),
configured model name non-empty, and network policy permits the base URL.
Doctor makes **no** provider network request in this batch; the existing
PyPI update check is gated behind an offline-safe knob introduced here.
All diagnostics report PASS / SKIP / FAIL with actionable hints.
