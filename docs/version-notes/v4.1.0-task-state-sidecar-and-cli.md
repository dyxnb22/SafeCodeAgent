# v4.1.0 task-state-sidecar-and-cli

## Summary

v4.1.0 implements T-4.1.0-A (task-state-sidecar) and T-4.1.0-B (task-cli-core) from
the v4.1–v4.8 shell-first roadmap. All new surfaces are **[EXPERIMENTAL]**.
No stable public contracts are added or changed.

## Changes

### T-4.1.0-A task-state-sidecar

- New `src/safecode/task/state.py`: `TaskState` Pydantic model with fields
  `task_id`, `goal`, `created_at`, `updated_at`, `status` (open|applied|interrupted|closed),
  `pending_patch_id`, `session_id`, `audit_trace_ids`, `iterations` (`TaskIteration` list),
  `last_command` (`TaskCommand`), `payload_version` (always 1).
- New `src/safecode/task/store.py`: `TaskStore(project_root)` with `create()`, `load()`,
  `save()`, `list()`, `current_id()`, `set_current()`, `clear_current()`, `delete()`.
- File layout: `.sac/tasks/<task_id>.json` (atomic), `.sac/tasks/INDEX` (sorted lines),
  `.sac/tasks/CURRENT` (single line).
- All writes are atomic via `tmp + os.replace`.
- Refuses to overwrite a sidecar whose `payload_version > 1` (fail closed).
- Missing files never cause exceptions on read paths.
- `task_id` is kebab-case and ≤39 characters (slug from goal + short SHA-256 hash).

### T-4.1.0-B task-cli-core

- New `src/safecode/cli_task.py`: `sac task new|list|show|switch|close|delete`.
- Registered in `src/safecode/cli.py` as the `task` group.
- `new <goal>`: requires non-empty goal; auto-generates task_id; sets CURRENT.
- `list`: sorted by `created_at` descending (newest first); marks current task.
- `show [<id>]`: defaults to CURRENT; redacts secrets via `redact_secrets()`.
- `switch <id>`: updates CURRENT.
- `close [<id>]`: sets `status=closed`.
- `delete <id>`: requires `--yes` guard.
- All subcommands support `--json` via `CLIJSONResponse` (stable contract 11).

## Tests

- 58 new tests in `tests/test_task_state.py` and `tests/test_cli_task.py`.
- Coverage: roundtrip, atomic write, missing files, CURRENT pointer, deterministic list,
  payload_version validation, JSON output shape, redaction, delete `--yes` guard.
- Full suite: 3842 passed, 2 skipped.
- Contract snapshot tests (`tests/test_public_contract_snapshots.py`): 93 passed.

## Invariants preserved

- `PatchProposal` field set unchanged.
- `AuditEvent` field set unchanged.
- No stable contract added or promoted.
- Default LLM provider remains `mock` in tests.
- No telemetry, no network, no auto-apply introduced.
