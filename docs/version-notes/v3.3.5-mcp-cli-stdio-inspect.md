# v3.3.5 — MCP CLI Stdio Inspect/Discover (Experimental)

## Summary

Adds two experimental commands to `sac mcp` for inspecting and discovering stdio MCP servers:

- `sac mcp stdio-status <server>` — reads config only, reports whether stdio argv is configured; no subprocess.
- `sac mcp stdio-discover <server>` — resolves argv, calls `discover_stdio_tools` (tools/list only), shows discovered tools; no tools/call.

Both commands are clearly labeled EXPERIMENTAL in help text and output. Both support `--json` via the existing `CLIJSONResponse`/`render_json` pattern.

## Safety Properties

- `stdio-status`: no subprocess is launched; reads `.sac/mcp.toml` only.
- `stdio-discover`: only `tools/list` is called — no `tools/call` is issued from the CLI.
- Both commands fail closed on missing server or missing argv; error text never contains argv content.
- MCP stdio remains experimental; not promoted to stable contract.
- Existing `sac mcp tools`, `call-readonly`, `propose-write`, `pending`, `discard` commands unchanged.
