# v4.16.1 - Config Migration and Legacy LLM Audit

## Summary

Adds `sac config migrate` to convert legacy `[llm]` settings into provider
profiles, plus doctor warnings and precedence-trace visibility.

## Changes

- `sac config migrate`: reads legacy `[llm]` from user config, converts to
  `[providers.<name>]`, writes `.bak` backup. Safe to re-run.
- `sac doctor`: new `legacy_llm_section` diagnostic warns when `[llm]`
  section still has a non-mock provider configured.
- Migration never prints secrets and uses `_render_user_toml()` for
  correct nested-section output.

## Tests

- `tests/test_config_migrate.py`: 4 tests covering no-config, legacy-llm
  migration with backup verification, and mock-provider skip.
