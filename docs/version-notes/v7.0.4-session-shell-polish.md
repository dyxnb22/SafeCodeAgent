# v7.0.4 — Session and Shell Polish

v7.0.4 improves human session navigation without changing session storage
contracts.

## Changed

- Added `safecode.report.session_timeline` to project agent journal events into
  compact human timeline rows.
- Added `sac session show <id> --timeline`.
- Added `sac session resume <id>` for passive agent-session resume through the
  existing `AgentLoop.resume_from()` path.
- Extended `sac session list` to include agent-journal sessions alongside
  shell sessions.
- Added shell slash commands:
  - `/timeline`
  - `/sessions`
  - `/resume <id>`

## Contract Status

- Timeline output is human-oriented and experimental.
- No stable machine-readable timeline contract is introduced.
- No session storage schema changed.
