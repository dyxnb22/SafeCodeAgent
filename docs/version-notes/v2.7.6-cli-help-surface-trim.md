# v2.7.6 cli-help-surface-trim

## Goal
Reduce noise in `sac --help` for new users without removing or breaking any commands.

## Changes
- Hidden from `sac --help` (still fully callable): `queue`, `memory`, `progress`, `rules`, `tui`, `ide`, `export`.
  - Sub-apps: `hidden=True` added to `app.add_typer()` calls in `src/safecode/cli.py`.
  - Root commands (`memory`, `rules`): `hidden=True` added to `@ops_app.command()` decorators in `src/safecode/cli_ops.py`.
- Core new-user commands remain visible: `setup`, `quickstart`, `ask`, `edit`, `apply`, `rollback`, `run`, `doctor`, `version`.
- No commands removed; no help text removed; backward compatible.

## Tests
- `tests/test_cli_help_surface_trim.py`: 23 tests verifying hidden commands absent from root help, hidden commands still callable, and core commands visible.

## Safety
No functional changes; only help visibility flags.
