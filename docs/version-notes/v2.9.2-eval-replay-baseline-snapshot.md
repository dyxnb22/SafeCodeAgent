# v2.9.2 — eval-replay-baseline-snapshot

## Summary

Snapshot deterministic typed traces for all six loop eval fixtures.
Traces contain only typed fields (tool intent types, targets, step counts,
patch hashes) — no LLM prose, no timestamps, no unstable absolute paths.
Snapshot tests are deterministic across repeated local runs.

## New types

- `LoopStepTrace(frozen dataclass)`: `step_index`, `tool_intent_type`,
  `tool_intent_target`, `is_stop_for_user`, `is_first_fail_recoverable`.
- `LoopEvalTrace(frozen dataclass)`: `fixture_name`, `steps: tuple[...]`,
  `expected_pending_patch`, `patch_hash` (SHA-256 hex of joined
  `expected_patch_contains` fragments, or `None`).
- `build_loop_eval_trace(fixture) -> LoopEvalTrace`: derives trace from
  fixture definition; no runtime LLM calls; byte-identical across runs.
