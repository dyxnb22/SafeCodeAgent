# v2.9.9 - Public Contract Snapshot Tests

## Summary

Adds narrow public contract snapshot tests for the v3.0-supported local safety contracts.

## Changes

- `tests/snapshots/contracts/config_defaults.json`: Snapshot of SafeCodeConfig field names and
  documented safe defaults, known policy names, and config lowering rules.
- `tests/snapshots/contracts/pending_patch_schema.json`: Snapshot of PatchProposal and PatchBlock
  field names and types.
- `tests/snapshots/contracts/audit_event_schema.json`: Snapshot of AuditEvent field names,
  hash-chain invariants, and known event types registered in the ToolSpec registry.
- `tests/snapshots/contracts/sandbox_schemas.json`: Snapshot of SandboxExecutionProposal,
  SandboxExecutionApproval, and SandboxExecutionResultRecord field names and lifecycle description.
- `tests/snapshots/contracts/eval_trace_schema.json`: Snapshot of LoopStepTrace and LoopEvalTrace
  field names and determinism invariants.
- `tests/test_public_contract_snapshots.py`: 51 new contract snapshot tests.

## Snapshot invariants

- All snapshots use sorted keys and stable indentation (JSON, no comments).
- No timestamps, absolute paths, host-specific data, random IDs, or git-specific values.
- Local ToolSpec registry snapshot reused from v2.9.8 (`tests/snapshots/registry/tool_registry_v1.json`).
- Loop fixture snapshots reused from v2.9.2 (`tests/snapshots/loop/*.json`).

## Not snapshotted

- Full `SafeCodeLocalAPI` (beyond `ask()` and `report()`) — experimental.
- Real-provider LLM behavior — experimental.
- MCP JSON-RPC behavior — experimental.
- Subagent concurrent execution behavior — experimental.
- TUI and IDE surfaces — experimental.
