# v4.10.1 — DeepSeek Setup Wizard Option

## Summary

Extends the `sac setup --wizard` flow to include a `deepseek` preset option.
When the user selects `deepseek`, the wizard resolves `DEEPSEEK_API_KEY` from
the environment, writes the `base_url` and `default_model` from the preset
table, and confirms configuration with a summary panel. Existing `openai` and
`openai-compatible` wizard paths are unaffected.

## Changed Files / Modules

- `src/safecode/cli.py`: added `deepseek` branch to `run_setup_wizard`.
- `src/safecode/llm/deepseek.py`: `DEEPSEEK_PRESET` constant consumed by the wizard.
- `tests/test_setup_wizard.py`: wizard selection, env resolution, config write,
  and existing-provider-unchanged tests.

## Tests Run

Targeted: `tests/test_setup_wizard.py` (all pass).
Full suite clean.

## Safety / Contract Note

No new stable contracts promoted. All new surfaces are EXPERIMENTAL.
Wizard never overwrites explicit user config values and always requires
interactive selection; no auto-write path.
