# v4.16.2 - Error-message Rewrite and sac why

## Summary

Adds `next_command` property to `FailureCategory` and a new `sac why`
top-level command for one-line failure recovery.

## Changes

- `FailureCategory.next_command`: property returning the mapped suggested
  next command for each of the 18 failure categories.
- `sac why` (hidden, callable): prints last failure's problem, category,
  and next command in <=3 lines. Shortcut for `sac debug last-failure --short`.
- Reuses existing `find_last_failure()` from cli_debug.py.

## Tests

- `tests/test_failure_taxonomy_next_command.py`: 4 tests covering all 18
  categories, next_command property, unknown fallback, and sac why output.
