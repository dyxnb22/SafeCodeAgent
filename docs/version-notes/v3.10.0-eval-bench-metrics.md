# v3.10.0 — eval-bench-metrics

## Summary

- T-3.10.0-A `sac eval bench`: new `src/safecode/eval/bench.py`; `EvalBenchRunner` runs all loop fixtures collecting wall time, step count, and pending-patch hash; baseline snapshots under `tests/snapshots/bench/` (written on first run); regression detection within ±20% tolerance using a mocked-clock-injectable design for deterministic CI tests; `sac eval --mode bench` CLI; `--update-baseline` flag to refresh snapshots; 27 new tests in `tests/test_eval_bench.py`.
- T-3.10.0-B live-session-metrics: new `src/safecode/metrics/writer.py`; `MetricsWriter` writes JSONL to `.sac/metrics.jsonl`; disabled by default; enabled via `SAFECODE_METRICS=1`; captures step start/end, tool intent, pending patch size (byte count only — content not stored), retry count; size-bounded at 1 MiB per session; never raises into user workflow; minimal integration in `AgentOrchestrator.edit()`; 26 new tests in `tests/test_metrics_writer.py`.
