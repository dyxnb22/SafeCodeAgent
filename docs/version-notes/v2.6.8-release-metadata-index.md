# v2.6.8 — Release Metadata Index

## Summary

Adds a lightweight release metadata helper so package version, runtime version, git tags, version-note files, and SKILL.md baseline can be audited in one command.

## Changes

- `src/safecode/release/metadata.py` (new): `ReleaseMetadata` dataclass; `collect_release_metadata()` accepts injected values for testability (package version, tag, paths); reports missing version-note and stale SKILL.md as issues; `render_release_metadata()` for human-readable output.
- `src/safecode/cli_ops.py`: added `sac release meta` command.

## Test coverage

`tests/test_release_metadata.py` (new):
- Correct package/runtime version returned
- Injected tag values (string, None)
- `has_version_note` True/False; missing note added to issues
- `skill_mentions_version` True/False; stale skill added to issues
- `ok` True when both checks pass
- `version_note_files` lists all .md files in notes dir
- Render includes version, tag, note count, issue text
- CLI exits 0 on clean metadata, non-zero on issues
