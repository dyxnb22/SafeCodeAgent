# v6.28.0 — opencode alignment train (v6.24–v6.28)

## Summary

Five-version train closing the capability gap with opencode for terminal-only use.
All 6016 tests pass. v6.0.0 remains the latest major stable-contract cut.

## Changes

### v6.24 — LLM-backed conversation compaction
- `ConversationBuffer.compact_with_llm(llm_client)` — generates a structured
  LLM summary of the oldest 10 turns, preserving goals, files modified, key
  decisions, rejected approaches, and open questions.
- `AgentLoop.native_step()` triggers LLM compaction when `turn_count > 12`
  (threshold); fails-soft to string-based fallback on LLM error.
- Validated with real DeepSeek API: generated summary correctly captured
  goals, file paths, approach decisions, and open questions from a 12-turn session.

### v6.25 — `search_symbol` native tool
- `search_symbol(name, kind?, file?)` — finds where a symbol is defined across the project.
- Backend 1: ripgrep (`rg --json`) if available.
- Backend 2: pure-Python walk with definition-pattern regex.
- Python files get AST-based kind labeling (function/class/import/variable).
- Returns `[{file, line, kind, snippet}]` capped at 50 results.
- Registered in `register_read_tools` alongside grep_files/search_files.

### v6.26 — full_auto CONFIRM-tier auto-apply
- Extended `auto_apply_condition` in `_execute_patch_proposal_step`:
  - `AUTO tier`: auto_edit OR full_auto (unchanged)
  - `CONFIRM tier`: full_auto only (new — multi-file edits apply without stopping)
  - `GATE tier`: always requires approval (unchanged)
- Multi-file agent edits in `--full-auto` no longer interrupt with stop-for-approval.

### v6.27 — Rich per-file diff rendering
- New `src/safecode/cli_diff_render.py`:
  - `render_rich_diff()`: splits unified diff into per-file Rich Panels with
    monokai Syntax highlighting and `+N/-M` change summary header.
  - `format_diff_for_plain()`: non-TTY fallback.
- Wired into `sac edit` (pending-patch display), `sac apply` (preview), `sac diff --task`.

### v6.28 — AI-generated commit message
- `sac commit --ai`: `_generate_ai_commit_message()` collects git diff (4KB cap,
  secrets redacted), calls LLM for a conventional-commit message (`type(scope): subject`).
- `--dry-run`: print message without committing.
- `--yes`: skip confirmation prompt.
- Fallback: clear error + hint to use `--message-from-task` on LLM failure.
