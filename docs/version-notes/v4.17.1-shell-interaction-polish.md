# v4.17.1 - Shell Interaction Polish

## Summary

Adds readline history with dedup, slash-command tab completion, `/clear`
command, and Rich Markdown rendering for LLM responses in `sac shell`.

## Changes

- `cli_shell.py`: new `_setup_readline()` configures GNU readline with:
  history file at `~/.safecode/shell_history`, 1000-entry cap, consecutive
  duplicate suppression, and tab completion for all 12 slash commands.
  New `_maybe_render_markdown()` renders responses with Rich Markdown
  when content contains code blocks, headings, or tables. New `/clear`
  slash command resets shell context. Shell banner updated to v4.17.
  Response rendering uses `_maybe_render_markdown` for all TTY output.

## Tests

- `tests/test_shell_interaction_polish.py`: 8 tests covering /clear intent,
  /help inclusion, slash command list, markdown rendering (plain, code blocks,
  non-TTY), and banner version.
