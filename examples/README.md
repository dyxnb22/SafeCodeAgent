# SafeCode Examples

Use `sac demo list` to inspect built-in workflows and `sac demo materialize WORKFLOW_ID` to create a local seed project.

Recommended onboarding workflows:

- [fastapi-todo](fastapi-todo/) is a small FastAPI todo API for the resume-ready agent demo. It starts with `GET /todos`, `POST /todos`, an in-memory store, and baseline tests so the natural follow-up task is adding `DELETE /todos/{id}` with a passing test.
- `failing-test-repair`
- `fastapi-health-endpoint`
- `docs-safety-note`
- `safe-shell-status`
