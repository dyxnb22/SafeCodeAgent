# Enterprise Technical Documentation

SafeCodeAgent Enterprise is feature-frozen. This directory documents the final
system rather than its implementation chronology.

## Start Here

- `architecture.md` — concise system map and trust boundaries.
- `platform-architecture-v2.md` — detailed service, workflow, data,
  integration, governance, and observability architecture.
- `workflow-design.md` — business workflows, state transitions, approvals, and
  failure paths.
- `data-models.md` — durable state and public data contracts.
- `security-governance-plan.md` — policy precedence, RBAC, approvals, audit,
  redaction, and action matrix.
- `deployment-profiles.md` — local, Team Server, and on-prem deployment shapes.

## Focused References

- `rag-and-context.md` — permission-aware retrieval and context assembly.
- `mcp-and-tools.md` — governed tool and MCP integration.
- `observability-and-evaluation.md` — traces, evidence, and deterministic
  evaluation.
- `security/threat-model-v2.5.md` — current threat model.
- `security/security-review-v3.0.md` — candidate security review.
- `security/external-gates.md` — external evidence still required for GA.
